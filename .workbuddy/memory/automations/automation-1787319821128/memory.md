# 自动化记忆 · 书稿每日「今日 AI 进展」流水线

任务链路：`node scripts/gen-daily.mjs book` → `node scripts/review-content.mjs sources` → `node scripts/prepare-deploy.mjs`

## 关键路径与约定

- 书稿目录：`website/book/pages/`（共 32 章 HTML），**不是**根目录的 `book/`
- 轮转游标：`data/.gen-cursor.json` 的 `bookIndex`，每次执行后自动 +1（对 32 取模）
- LLM 渠道优先级：智谱 GLM-4.7-Flash(免费) → 方舟豆包 → DeepSeek，脚本内置自动降级
- 审查脚本 `review-content.mjs sources` 覆盖全站 174 页的诚实/出处标注检查
- `prepare-deploy.mjs` 会把 DeepSeek/ARK 密钥注入 `deploy/ai-client.js`，产物约 148 MB

## 验证要点（每次执行后自查）

1. 源文件与 `deploy/` 副本都要能 grep 到当天日期的「今日 AI 进展」小节
2. 更新章节内需含「出处 / 来源」字样
3. `bookIndex` 已递进
