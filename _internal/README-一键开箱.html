README · 一键开箱启动本地网站

本项目 website/ 目录是一个纯静态网站（HTML/CSS，无需安装任何依赖、无需构建）。 下面三种方式都能打开它，从「双击即看」到「发到网上让手机访问」，由简到繁。

方式一：双击脚本，一键启动（最简单，推荐）

你的系统 操作 脚本
Windows 双击 start.cmd（项目根目录下） start.cmd
macOS / Linux 终端执行 chmod +x start.sh && ./start.sh start.sh

脚本会做三件事：

  1. 自动切到项目根目录（cd /d %~dp0 或 cd "$(dirname "$0")"）；
  2. 自动找 Python（python / python3 / py），找不到会给出安装提示；
  3. 用 python -m http.server 8000 --bind 0.0.0.0 启动一个本地静态服务器。

启动成功后，浏览器打开：

http://localhost:8000/website/

停止服务：回到那个命令行窗口，按 Ctrl+C 即可。 若双击 start.cmd 一闪而过：多半是没装 Python，或没勾选 "Add python.exe to PATH"； 先按方式二手动跑一次看报错。

方式二：手动用 Python 起服务器（一条命令）

只要电脑装了 Python（3.x），任何系统通用：

# 1) 进入项目根目录（有 website/ 的那一层）
cd /d C:\Users\35683\CodeBuddy\20260815143624    # Windows（cmd）
# 或
cd ~/你的路径/项目根目录                            # macOS / Linux

# 2) 启动服务器（默认监听 8000 端口）
python -m http.server 8000
# （macOS/Linux 若提示找不到 python，改用 python3 -m http.server 8000）

# 3) 浏览器打开
#    http://localhost:8000/website/

服务器启动后会一直占用这个终端窗口，按 Ctrl+C 停止。 端口 8000 被占用时，换成别的端口，如 python -m http.server 8080，网址也相应改成 :8080/。

方式三：部署到网上（让手机在任何地方都能访问）

本地服务器只能让「和你同一台电脑 / 同一 WiFi」的设备访问。 想让手机走出家门也能打开，就把它免费部署到公网：

  • GitHub Pages：按 lab/cicd/自动部署指南.md 一步步做，得到 https://用户名.github.io/仓库名/。
  • Vercel / Netlify：网页拖拽上传 website/ 文件夹，几十秒得到一个 https://xxx.vercel.app 或 https://xxx.netlify.app 网址。

详细命令与截图位见 lab/cicd/自动部署指南.md。

附：手机访问本机 8000 端口（同一 WiFi 下）

前提：手机和电脑连的是同一个 WiFi（路由器）。手机数据流量（4G/5G）访问不到本机。

第 1 步：查出电脑的本机 IP（局域网 IP）

系统 命令 看哪一行
Windows ipconfig 找「无线局域网适配器 WLAN」或「以太网适配器」下的 IPv4 地址，形如 192.168.x.x
macOS ipconfig getifaddr en0 直接打印，形如 192.168.x.x
Linux hostname -I 或 ip addr 第一个 192.168.x.x

📸【截图位：ipconfig 输出，红框标出 IPv4 地址】

第 2 步：用 --bind 0.0.0.0 启动（让服务器对外网卡也监听）

python -m http.server 8000 --bind 0.0.0.0

--bind 0.0.0.0 表示监听所有网卡（含局域网网卡）。缺少它时，部分环境可能只监听 127.0.0.1（本机回环），手机就连不上了。本项目自带的 start.cmd / start.sh 已经写上了 --bind 0.0.0.0，直接双击即可，无需手动加。

第 3 步：手机浏览器打开

http://192.168.1.100:8000/website/
        └────┬────┘
          换成你第 1 步查到的本机 IP

📸【截图位：手机浏览器地址栏输入 http://192.168.x.x:8000/website/，显示网站首页】

打不开？逐条排查

  1. 电脑防火墙拦截了 8000 端口（最常见）。Windows 首次运行 python 起服务器时， 若弹出「Windows Defender 防火墙」提示，勾选「专用网络」并点「允许访问」； 没弹窗也可手动在「防火墙 → 允许应用通过防火墙」里放行 Python。
  2. 手机没和电脑连同一个 WiFi（例如手机用了数据流量）。确认两边都在同一路由器下。
  3. IP 填错：确认填的是电脑的 IPv4（192.168.x.x / 10.x.x.x），不是公网 IP， 也不是 127.0.0.1（那是电脑自己）。
  4. 端口占用：换 8080 等其它端口重试。

想彻底摆脱「同一 WiFi」限制，就用上面的方式三部署到公网，手机随时随地可访问。

三种方式对比

方式 门槛 谁能访问 适合场景
① 双击脚本 零（装个 Python 就行） 本机 本地预览、开发调试
② 手动命令 极低 本机 无脚本环境、临时预览
③ 部署到网上 需一个 GitHub 账号 任何人（含手机 4G/5G） 分享给别人、长期在线
