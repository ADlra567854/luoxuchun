AI 工具全景图（国内 + 国外，2026 版）

怎么看这张图

按「你要做什么」分六大类。小白不需要每个都用，每类先掌握 1 个就行，用到哪类再深挖。

1. 对话 / 写作（最核心，先学这个）

  • 国外：ChatGPT（GPT-5.4 系列）、Claude、Gemini
  • 国内：DeepSeek、豆包、通义千问、文心一言、智谱

能干什么：写文案、改稿、翻译、总结长文、头脑风暴、做选题。

小白首选：DeepSeek（便宜 + 中文强）或 ChatGPT。

2. 图像生成

  • 国外：Midjourney（美术质感天花板）、Flux（开源）、DALL-E、NanoBanana Pro
  • 国内：即梦、可灵、腾讯混元绘图、通义万相

能干什么：配图、封面、海报、头像、漫画、产品图。

小白首选：即梦 / 可灵（国内注册方便，出图也快）。

3. 视频生成

  • 国外：Sora、Veo、Runway
  • 国内：可灵（Kling 3.0）、剪映（剪辑 + AI 一站式）

能干什么：文生视频、图生视频、数字人、配音、剪辑。

小白首选：剪映 + 可灵（剪辑和 AI 生成都覆盖）。

4. 编程 / IDE（详见 04 号文）

  • 国外：Cursor、Windsurf、GitHub Copilot、Claude Code、Codex、Gemini CLI
  • 国内：通义灵码、腾讯云 AI 代码助手

能干什么：让 AI 帮你写代码、改 bug、做网页、做小程序。

小白首选：Cursor（体验最好）。

5. 搜索 / 浏览

  • 国外：ChatGPT Search、Perplexity、Gemini
  • 国内：秘塔 AI 搜索、夸克、豆包

能干什么：联网查最新资料、做调研、找案例、核实信息。

小白首选：秘塔 / Perplexity（带来源，好核实）。

6. 审阅 / 校对 / 效率

  • 代码审阅：CodeRabbit、GitHub Copilot Code Review
  • 文字审阅：Grammarly、秘塔写作猫、各类 AI 校对
  • 办公效率：Notion AI、WPS AI、飞书 AI、腾讯文档 AI

能干什么：给代码和文章「挑错」，帮做 PPT、表格、会议纪要。

国内 + 国外怎么搭配

一句话：用国外最强做「创意 / 代码」，用国内最方便做「分发 / 剪辑」，用 DeepSeek 做「性价比主力」。

免费 vs 付费

  1. 先用免费版把流程跑通。
  2. 等确定它能带来收益，再为一个工具付费。
  3. 警惕「订阅陷阱」：很多工具自动续费，记得去设置里关掉或做提醒。

下一步

  • 想写文章 学 DeepSeek 提示词
  • 想做视频 剪映 + 可灵
  • 想建网站 Cursor

一次只推进一条线，不要同时开太多。

本节原为按日滚动的「今日 AI 进展」，内容是早期自动生成的，里面的份额、增速、延迟降幅等具体数字无法逐条溯源，且与新版官方资料冲突，已整体撤下。下面替换为按各厂官方定价页核对后的稳定事实，逐条出处见文末「参考来源」。没有可靠来源的维度（市场份额、榜单排名、月活规模）不再给出数字——宁可留白，也不编一个看起来很像真的数。

工具选型的第一步不是比参数，是比"你现在要为哪一档付钱"。三家海外厂都做成了旗舰 / 主力 / 轻量三层，层与层之间差 5 到 100 倍；国内两家（DeepSeek、智谱）在主力档上的价格明显低一截，DeepSeek 还叠了峰谷两档。下面这张表是各厂官方定价页的标价档，不含促销与批量折扣。

通用计费规则

  • 输入与输出分开计价，输出通常是输入的 5 倍，各家旗舰档基本一致。
  • 缓存命中大幅打折，但写缓存本身可能溢价（Anthropic 5 分钟缓存 1.25 倍、1 小时 2 倍）。
  • 长 prompt 可能跳档加价：各厂长上下文加价规则不同且常变，具体分界与倍数以各厂当前定价页为准（本站未能逐条核实 OpenAI 的分界值，故不写具体数字）。
  • 推理 token 按输出计费，思考越长账单越高，但不改变最终可见答案的长度。
  • 不同厂 tokenizer 不同，同样文字切出的 token 数可差约 30%，横向比价不能只看单价。
  • 批量（Batch）异步处理普遍约 5 折，适合离线评测，不适合交互式 Agent。
