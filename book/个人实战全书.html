一、漫画 / 漫剧提示词库

提示词不是越长越好，是要素越具体越好。下面是可复制的模板，填括号里的内容即可。

① 生图提示词（角色 / 场景）

主体：[银发少女，手持发光长剑]
风格：[动漫二次元 / 写实摄影 / 水墨国风 / 赛博朋克]
场景光线：[雨夜霓虹街道，侧逆光，湿地面倒影]
画幅：[半身特写 / 全身 / 电影感中景]
画质：高细节，8k，电影级打光，最佳画质
负面词：模糊、畸形、水印、多余手指、低质

技巧：角色一致性用「[角色名]：银发/蓝眼/红色斗篷」固定描述，每帧都带。

② 分镜提示词（给生图 / 生视频）

镜头[3]：[中景]主角在[废弃车站]醒来，[冷蓝色调]，[慢推镜头]
生图提示词：同上角色设定 + 该镜头的场景与机位
生视频提示词：[镜头缓慢右移，氛围紧张，8秒，电影感]

③ 漫剧台词 / 剧本口播

角色：[白驹] 语气：[沉稳带笑]
台词：「你以为终点在远方？不，第一步，就在你按下生成的这一秒。」

二、漫画剧本模板（直接抄）

5 镜头迷你漫剧骨架

  1. 建立世界观：用 1 句话交代时间与规则（例：2099 年，记忆可买卖）。
  2. 主角登场：给出主角的渴望与缺陷。
  3. 冲突发生：平静被打破，目标出现。
  4. 高潮转折：主角用「AI 能力」破局（呼应本集主题）。
  5. 留悬念结尾：抛出一个更大的问题，引下一集。

每集套这个骨架，再给每个镜头配「生图提示词 + 台词」，就是一条能做的剧。

三、各 AI 工具部署清单

DeepSeek（对话 / 推理）

  • 云端：拿官方 API Key，填进本站「 设置」即可用。
  • 本地：装 Ollama ollama run deepseek-r1，零代码。
  • 验证：问一句「1+1 等于几」，有回复即通。

Ollama（本地模型底座）

  • 官网下安装包 终端 ollama serve 启动。
  • 拉模型：ollama pull llama3 / deepseek-r1。
  • 本站「本地 AI」页可一键对接。

ComfyUI（生图工作流）

  • 装 Python + 显卡驱动（N 卡优先）。
  • git clone 官网仓库 pip install -r requirements.txt。
  • 启动后浏览器开 127.0.0.1:8188，拖节点搭工作流。

AI 智能体（Agent）

  • 搭：用 Coze / Dify 可视化建（不用写代码）。
  • 连：给智能体配「工具 / 知识库 / API Key」三类接入。
  • 跑：本站「 全能智能体」页可直接对话调度。

AI 工作站（IDE × GitHub）

  • 装 VS Code / Cursor，装 AI 插件（通义/Copilot）。
  • 建 GitHub 仓库 插件读代码、写代码、提 PR。
  • 本站「白驹工作站」页有模板一键起。

知识库（个人 / 团队）

  • 把文档扔进 Dify / 本地 RAG 框架。
  • 切分 向量化 接模型问答。
  • 用途：论文助手、客服、个人第二大脑。

四、智能体怎么「连接」

连接的本质 = 给智能体三样东西：身份（它是什么） + 能力（能调哪些工具/API） + 记忆（知识库/历史）。
  1. 在 Coze / Dify 新建智能体，写「角色设定」。
  2. 添加「插件 / 工作流」作为能力（如联网、生图、查天气）。
  3. 上传文档作为知识库，开启「长期记忆」。
  4. 发布为 API，本站「全能智能体」或你的网站即可调用。

五、实战第一步

别想「先学完再干」。今天就做三件：

  • ① 用本站「 生图」生成你的第一个角色。
  • ② 用「 生视频」把上面的 5 镜头骨架变成分镜。
  • ③ 用「 全能智能体」把分镜细化成可拍脚本。

做完这三步，你就已经拥有了一条「AI 漫剧生产线」的雏形。

六、为什么你的漫剧「看着像 AI 做的」

这是新手最常见的挫败：每一张图单看都还行，连起来一看就不对。说不清哪里不对，但就是像 AI。原因通常不在画质，在三个地方。

第一个是不统一。同一个角色，第二格比第一格瘦了一点，眼睛颜色偏了一点，衣服领子换了款式。模型每一张都是重新理解你的描述，它不会记得上次画了什么。解法只有一个：锁参考图。能用角色参考、图生图、固定种子的时候一定用，别指望文字描述能锁住一张脸。

第二个是不讲究光。AI 出图默认的光照很平，谁也不像在真实环境里。人眼看画面，先看光影关系。想让画面有质感，最省事的办法是在提示词里明确写光从哪来——侧逆光、窗光从左侧、夜晚路灯暖光这类词，比堆一百个形容美的词有用得多。

第三个是镜头没有变化。一整段全是中景、全是正面、全一样的高度。真人拍的东西会有特写、有过肩、有俯仰。这个问题跟画画无关，是分镜意识的问题。补法也很土：找一部你喜欢的片子，把它的镜头节拍抄下来，照着排一遍。

七、一条能持续干下去的生产节奏

做内容最容易死在「热情期结束了」。前三天一天做五条，第四天做两条，第五天不做了。这跟懒不懒没关系，是节奏设计错了。

比较能持续的排法是把「生产」和「发布」分开，而且都定死时间。

  1. 每周固定一天攒素材：批量出图、批量生成片段，不追求成品。
  2. 每周固定一天做组装：把攒好的素材剪成两三条。
  3. 发布用定时，不用临时。定时发布能让你在没状态的时候也不断更。

关键在「批量」这两个字。出图和剪辑的切换成本很高，每次切换都要重新进入状态。一次做十张图，远比十次各做一张图快，也更容易保持风格一致。

还有一条：先把模板跑顺，再谈创意。第一条片子就该用最笨、最稳的做法做出来并发布，哪怕它很粗糙。跑通一次完整流程，比在纸上想十个创意有用得多——因为流程里那些坑，只有你真的走过才知道。
