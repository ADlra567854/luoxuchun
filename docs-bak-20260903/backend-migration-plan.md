# 白驹 · 自有后端 + 独立部署迁移计划

> 当前站点为纯静态前端（HTML/CSS/JS + 第三方 AI API），API 密钥直接暴露在前端。本计划描述如何迁移到「自有后端 + 自有服务器 + 自有域名」，实现数据归属、安全可控、可商业化。

---

## 一、目标架构

```
用户浏览器  ←──HTTPS──→  自有域名 + Nginx
                              │
                              ▼
                     Node.js / Express 后端
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
   AI 模型网关            业务数据库            文件/资源存储
   （仅服务端持有密钥）    SQLite / Postgres    本地磁盘 / 对象存储
```

---

## 二、需要采购的资源

| 资源 | 推荐方案 | 预算参考 |
|---|---|---|
| 云服务器 | 腾讯云轻量应用服务器 2 核 4G / 阿里云 ECS 入门型 | 80–150 元/月 |
| 域名 | `baiju.cc` / `ccowork.cn` / `ccowork.com.cn` | 30–80 元/年 |
| SSL 证书 | Let's Encrypt（免费）或云厂商免费证书 | 0 元 |
| 对象存储（可选） | 腾讯云 COS / 阿里云 OSS，用于用户生成图片/视频 | 按量计费 |
| 数据库 | 服务器本地 SQLite 或免费 RDS 试用 | 0–50 元/月 |

---

## 三、后端能力拆分

| 当前前端能力 | 迁移后方案 |
|---|---|
| `ai-client.js` 直接调用方舟/DeepSeek API | 后端 `/api/chat` 代理，前端只发 prompt，密钥在服务端 |
| `media-gen.js` 调用智谱/豆包生图 | 后端 `/api/image` 代理，返回图片 URL 或 base64 |
| 本地存储用户数据 | 后端 `/api/session` + 数据库存储，支持多端同步 |
| 无用户系统 | 增加 JWT / 微信扫码登录（可选） |
| 静态资源部署在 CloudStudio | 迁移到自有服务器 + CDN |

---

## 四、后端 API 路由草稿

```
POST   /api/chat              AI 对话（统一网关，支持多模型）
POST   /api/image             文生图
POST   /api/video             文生视频
GET    /api/news              站点新闻列表
POST   /api/feedback          用户反馈
POST   /api/session           保存/恢复会话
GET    /api/health            健康检查
```

---

## 五、数据归属设计

- **用户数据**：聊天记录、生成图片、学习进度全部存储在用户自己的数据库记录中。
- **API 密钥**：统一由后端环境变量管理，前端不可见。
- **模型调用日志**：记录到后端日志，便于成本核算与故障排查。
- **内容安全**：后端统一做敏感词/内容审核，再转发到模型服务商。

## 七、前置决策

- 主域名选哪个？（推荐 `baiju.cc` 或 `ccowork.cn`）
- 是否需要在第一阶段就上用户登录？（可先 anonymous session，后续补微信登录）
- 是否需要保留 CloudStudio 作为备用部署？（建议保留，双活运行一段时间）

---

## 八、预期收益

- API 密钥不再暴露，防止被盗刷。
- 用户数据、生成记录属于自己，支撑商业化与合规。
- 可以接入支付、会员、内容付费等业务中心功能。
- 独立域名 + 自有服务器，品牌可信度提升，利于商标与融资。
