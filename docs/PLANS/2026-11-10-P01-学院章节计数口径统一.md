## 一、问题一句话

**站点对「AI 学院一共有多少章」给出了 4 个互相矛盾的数字**：43（学院页静态）、41（进度 JS）、32（路线图静态）、30（页脚徽章）。实际磁盘上有 **43** 个章节文件。

---

## 二、实测证据

### 2.1 真实章数 = 43

```
$ ls website/ai-academy/chapter-*.html | wc -l
43
$ ls website/ai-academy/chapter-*.html | sed 's/.*chapter-//;s/.html//' | sort -n | tail -1
43
```

`data/site-stats.json` 亦记为 `"chapters": 43`，与磁盘一致。

### 2.2 四套数字的来源

| 数字 | 位置 | 出现内容 | 影响的用户可见文案 |
|---|---|---|---|
| **43** | `learn/academy.html`（静态 HTML） | `0 / 43 章`、`43 章 · 每日新增`、`43 章 · 600 个知识原子 · 4 条路径` | 学院页标题区与课程地图，**首屏可见** |
| **41** | `module.js:656` | `var TOTAL_CHAPTERS = 41` | 所有带学习进度的页面 |
| **32** | `learn/roadmap.html:93` | `<span id="rmCount">0 / 32 章</span>` | 路线图页进度条初值 |
| **30** | `module.js:598` | `AI 学院 30 章` | **全站页脚徽章**，每页可见 |

### 2.3 线上实测（Playwright，模拟「已学 3 章」的回访用户）

| 页面 | 新用户（无进度） | 回访用户（有进度） |
|---|---|---|
| `/learn/academy.html` | `0 / 43 章` | **`3 / 41 章`** ← 数字变了 |
| `/learn/roadmap.html` | `0 / 32 章` | **`3 / 41 章`** ← 数字也变了 |
| 任意页页脚徽章 | `AI 学院 30 章` | `AI 学院 30 章`（从不更新） |

**根因**：`learn/academy.html` 与 `learn/roadmap.html` 都在**静态 HTML 里预置**了一个章数（43 / 32），
但页面加载后由 `module.js` 的 `renderAcademyProgress()` / 路线图渲染函数**用 `API.TOTAL_CHAPTERS`（=41）覆盖**。
于是：

- 新用户看到静态值（43 或 32）—— 因为进度为 0，代码走 `if (count > 0 || p.streak > 0)` 分支时不更新，静态值留在页面上；
- 老用户看到 JS 值（41）—— 每次都错。

**同时**：页脚徽章 `AI 学院 30 章` 从不更新，永久停留在建站时的章数。

## 三、影响面

| 影响 | 说明 |
|---|---|
| 用户信任 | 页脚每页都挂着「AI 学院 30 章」，点进去发现 43 章 —— 口径不一致是硬伤级别的观感问题 |
| 学习进度 | 用户学完 41 章时进度条已到 100%，但第 42、43 章**永远学不完**（`count` 封顶在 41） |
| 静态文案 | 学院页写「43 章」，进度显示「/ 41 章」，同一屏出现两个数 |
| 巡检脚本 | 每轮巡检都要人工核对章数，无法自动断言 |

## 四、修复方案（推荐 B 方案）

### 方案 A：改硬编码为 43（改动最小，但不治本）

把 `module.js:656` 改成 `43`，`learn/roadmap.html:93` 改成 `0 / 43 章`，`module.js:598` 改成 `AI 学院 43 章`。

- 优点：改 3 行，立刻一致。
- 缺点：**下次加第 44 章时又全部要改一遍** —— 这正是本问题反复出现的根因。

### 方案 B：单一真源 + 运行时注入（**推荐**）

1. **建真源**：新增 `data/academy-meta.json`，写 `{ "totalChapters": 43 }`。
2. **生成期注入**：在 `scripts/prepare-deploy.mjs`（或 `daily-update.mjs`）里，**扫 `website/ai-academy/chapter-*.html` 实际数量**，写入 `data/academy-meta.json`。
3. **运行时读取**：
   - `module.js` 不再硬编码 `TOTAL_CHAPTERS`，改为从 `/data/academy-meta.json` 取；取不到时回退到 `document.querySelectorAll('[data-chapter]').length`。
   - 页脚徽章 `AI 学院 N 章` 的 `N` 改为运行时填。
   - `learn/academy.html` / `learn/roadmap.html` 的静态初值改为占位 `0 / — 章`，由 JS 填真实值。
4. **验收**：新增章节 → 跑一次 `daily-update.mjs` → 全站章数自动变，无需改任何手写数字。

### 方案 C：让页面自己数（最彻底，成本最高）

学院页与路线图页在渲染时直接统计已渲染的课程卡片数，不依赖任何配置。适合未来章节数频繁变动、且页面结构稳定的场景；代价是两条渲染链都要改。
