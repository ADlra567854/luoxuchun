### 2.2 为什么「发布包带密钥」比「git 带密钥」更危险

`server.mjs:87` 的 `DENY_FILE` 是线上唯一的防线：

```js
const DENY_FILE = new Set(['server.mjs', 'server-legacy.mjs', 'package.json', 'package-lock.json', 'ai.config.json', '.env'])
```

**11-13 那轮已经实证过这条防线会失效**：线上退化成纯静态托管（`/api/health` 返回 46 字节静态桩、`Content-Type: application/octet-stream`）时，`DENY_FILE` 不再生效，10-29 的旧 `ai.config.json` 明文裸露了约 **13 小时**（00:00 — 13:20）。

也就是说：**只要再发生一次形态回退，密钥即刻在线上裸奔**，而发布包里现成就有这份明文可用。
