## 二、问题 A（🆕）：blog 页 canonical 指向 404

### 现象

`blog/2026年8月AI变现实录：别追风口了，这3条低门槛路径实际能赚多少.html` 的
`<link rel="canonical">` 写的是另一个不存在的标题：

```
实际文件：2026年8月AI变现实录：别追风口了，这3条低门槛路径实际能赚多少.html
canonical：2026年8月AI变现实录：别追风口了，这3个低门槛路径已经有人月入5万+.html
```

线上实测该 canonical 目标 **404**。全站 55 个带 canonical 的 blog 页中**仅此 1 处**不符，其余 54 处正确。

### 影响

- 搜索引擎收录该文时，会把权重归并到一个 404 地址 → 该文 SEO 权重丢失

### 建议方案（推荐：方案 A，改动最小）

把该文件 canonical 的 href 改为与自身文件名一致（URL 编码形式），改动 1 行。

```bash
# 目标文件
blog/2026年8月AI变现实录：别追风口了，这3条低门槛路径实际能赚多少.html
```

修正后需同步 `deploy/blog/` 镜像（若流水线未自动带出）并重发。

比对 href 的 URL 解码后是否等于源文件名，不一致则**构建失败**。

> 建议 A + B 一起做：A 修当前这 1 处，B 防将来再犯。

### 验收判据
