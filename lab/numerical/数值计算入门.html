数值计算入门

面向工科生的数值计算（Numerical Computation / Numerical Analysis）入门讲义。 配套脚本见同目录 01_newton_root.py ~ 05_interpolation.py，每个都可直接 python xxx.py 运行。

一、数值计算是什么

现实中的工程问题，最终大多会归结为一类数学问题：解方程、算积分、解微分方程、拟合数据、求极值等等。但这些问题的解析解（精确的公式解）往往不存在，或者形式过于复杂无法手算。

数值计算就是研究如何用有限步的四则运算，得到一个足够接近真值的近似解，并分析这个近似解的误差和可靠性。

对比 解析解（符号解） 数值解
形式 精确公式，如 x = (1+√5)/2 近似数值，如 x ≈ 1.618034
适用范围 只有少数问题能解出 几乎所有问题都能算
计算量 推导难，代入易 推导易，计算量大（交给计算机）
精度 精确 可控近似，够用即可

一句话：解析解是"少数幸运儿"的特权，数值解是工程实践的通用语言。计算机的出现让数值方法从"纸上的理论"变成了"手里的工具"。

例子：方程 x^3 - x - 2 = 0 有解析解（卡丹公式），但写出来是一长串根号嵌套，工程上没人用它；而牛顿迭代 5 步就能得到 1.5213797068，足够实用。

二、误差来源

数值计算永远带着误差，理解误差从哪来，是"会用"和"会用且不踩坑"的分水岭。

1. 模型误差（Model Error）

把现实问题抽象成数学模型时产生的偏差。例如把空气阻力忽略、把材料当成理想弹性体。

这是"建模"阶段的问题，不属于数值计算本身，但决定了结果的天花板。

2. 观测误差（Measurement Error）

模型中的参数来自测量，而测量必有误差。例如传感器读数、实验数据。

3. 截断误差（Truncation Error）

用有限项近似无限过程时产生的误差。这是数值方法固有的误差。

例如泰勒展开只取前几项、无穷级数截断、积分用梯形近似、微分用差商近似。

4. 舍入误差（Round-off Error）

计算机用有限位二进制表示实数，任何运算都可能丢失精度。

例如 0.1 + 0.2 != 0.3（浮点数表示误差）；两个接近的数相减会"灾难性抵消"。

5. 误差的累积与传播

  • 稳定性：算法会不会把小误差放大成大误差。
  • 病态问题（ill-conditioned）：输入的小扰动导致输出的大变化，这是问题本身"难算"，换算法也救不了。
  • 收敛阶：截断误差随计算量增加而下降的速度。记 O(h^p)，p 越大收敛越快。

经验法则：先保证算法稳定、问题良态，再追求高收敛阶。 二阶、四阶的经典方法（梯形 O(h²)、辛普森/RK4 O(h⁴)）对工科应用通常已经足够。

四、数值计算与仿真的关系

数值计算是仿真（Simulation）的地基。

  • 仿真 = 物理建模（写出支配方程）+ 数值求解（离散化 + 迭代）+ 可视化与验证。
  • 你看到的有限元分析（FEM）、计算流体力学（CFD）、电路仿真（SPICE）、控制系统仿真，本质都是：
    1. 把连续域（时间/空间）离散成网格和时间步；
    2. 把偏微分方程离散成大型代数方程组；
    3. 用本目录里的那类数值方法（积分、求导、迭代、线性代数）去求解。

一个典型的关联链条：

物理定律  微分方程（连续模型）
         离散化（有限差分 / 有限元 / 有限体积）
         数值方法（RK4、高斯消元、迭代法……）
         计算机求解  可视化  与实验对比验证

要点：

  • 仿真结果的误差，来自"建模误差 + 离散/截断误差 + 舍入误差"三者叠加，缺一不可忽视。
  • 会用商业软件（ANSYS、MATLAB/Simulink、COMSOL）不等于懂数值计算；懂底层方法才能看懂收敛、调对网格、判对结果。
  • 工科学数值计算的最终目的，是能判断"这个仿真结果可不可信"，而不是手推公式。

五、学习建议

  1. 先写代码，再看理论：每个方法亲手实现一遍（本目录 5 个脚本就是最小可运行版本），比读十页公式记得牢。
  2. 学会看误差：每次跑完都问一句"误差多大、随步长怎么变、方法几阶"。
  3. 无第三方依赖起步：先用纯 Python 理解算法本质，再学 NumPy/SciPy 享受现成高效实现。
  4. 对照解析解验证：凡是能算出解析解的问题（如 e^x、sin 的积分），先用它当"标准答案"检验你的代码，这是工程上的验证（Verification）习惯。
