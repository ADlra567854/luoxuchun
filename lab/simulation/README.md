## 脚本与结论

| 脚本 | 标题 | 结论 |
|---|---|---|
| `01_pid_controller.py` | PID 控制器仿真 | P-only 留稳态误差；I 消除余差但增大超调与调节时间；D 抑制超调、加快稳定。三者需按被控对象整定，不存在通用最优参数。 |
| `02_spring_mass_damper.py` | 弹簧-质量-阻尼系统仿真 | 阻尼比 ζ<1 欠阻尼振荡、ζ=1 临界阻尼最快且无超调、ζ>1 过阻尼缓慢回稳；固有周期只由 m 与 k 决定，与阻尼无关。 |
| `03_projectile.py` | 抛体运动仿真（含线性空气阻力） | 线性空气阻力使射程变短、轨迹不再是对称抛物线；真空解析解是射程上界，可用作数值实现的校验基准。 |
| `04_rc_circuit.py` | RC 电路暂态仿真 | 电容电压按 e^(−t/RC) 指数趋近稳态，时间常数 τ=RC；约 3τ 达 95%、5τ 达 99%，τ 只由 R、C 决定。 |
| `05_monte_carlo.py` | 蒙特卡洛求 π 与定积分 | π 与定积分的估计误差按 N^(−1/2) 下降：样本翻 4 倍误差才减半。想提精度要靠方差缩减，不是盲目加样本。 |
| `06_single_pendulum.py` | 单摆（非线性）仿真 | 小角度近似 T≈2π√(L/g) 只在大摆幅下失效；振幅增大周期变长。非线性模型无耗散时能量应守恒，数值积分会有微小漂移。 |
| `07_dc_motor.py` | 直流电机启动仿真（电气+机械耦合） | 启动瞬间反电动势为零、电流最大；转速上升后反电动势把电流压回稳态。电气与机械两个时间常数共同决定启动曲线形状。 |
| `08_heat_equation.py` | 一维热传导（显式差分） | 显式差分必须满足 r=αΔt/Δx²≤1/2，超限立刻数值发散；稳态温度分布由边界条件决定，与初始条件无关。 |
| `09_lotka_volterra.py` | 捕食者-猎物模型（Lotka-Volterra） | 捕食者-猎物数量呈周期性振荡且捕食者相位滞后；封闭无耗散系统振幅不衰减，数值格式不当会引入虚假阻尼。 |
| `10_wave_equation.py` | 一维波动方程（中心差分） | 一维波动方程用中心差分推进，CFL 数 cΔt/Δx≤1 才稳定；两端反射会形成驻波，能量不能拿单点幅值当无耗散判据。 |
