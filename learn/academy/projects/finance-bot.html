14 号毕业设计：FinanceBot 理财顾问

本项目针对普通用户记账无反馈、预算难落地、理财知识碎片化的痛点，打造对话式轻量理财顾问，完成后你将掌握LLM工具调用、金融数据结构化处理、RAG知识库搭建与端到端对话系统部署能力。

项目简介

FinanceBot理财顾问是面向个人用户的轻量对话式金融助手，定位为“口袋里的记账分析师+理财入门向导”，无需复杂的专业金融终端，仅通过自然语言对话即可完成日常收支记录、消费结构分析、月度预算调整建议、理财常识科普等高频需求。项目默认适配中文用户记账习惯，支持口语化收支录入（如“今天中午外卖花了32”），所有用户数据本地加密存储，避免敏感财务信息泄露，整体开发周期约2周，适合有Python基础、掌握大模型API调用的学习者作为AI应用落地的毕业设计项目。

功能特性

  • 口语化收支记账：支持自然语言录入收支，自动提取金额、分类、交易时间、支付渠道等结构化字段，无需手动填表单
  • 多维度账单分析：自动生成周/月/季度消费报表，识别餐饮、娱乐、通勤等分类占比，标记超常规消费的异常项
  • 个性化预算建议：结合用户历史消费数据、所在城市平均消费水平，给出各分类预算调整阈值，超支时主动触发提醒
  • 理财科普RAG问答：对接理财入门知识库，覆盖基金、保险、存款等低风险理财常识，拒绝生成高风险投资建议，所有回答标注信息来源
  • 消费预警提示：识别连续大额非必要支出、月光风险等问题，给出可落地的节流建议，不推送任何金融产品广告
  • 多端适配入口：支持命令行交互、微信公众号/飞书机器人快速接入，满足不同场景的使用需求

技术架构

组件技术选型作用
大模型推理层通义千问qwen-turbo / 智谱GLM-4-Air负责自然语言理解、工具调用决策、自然语言回复生成
工具调用层LangChain v0.2封装记账、查询、分析三类工具，实现大模型与本地数据的交互
数据存储层SQLite + SQLAlchemy 2.0存储用户收支记录、预算配置、自定义分类标签，轻量无需额外部署
知识库层LangChain-Chatchat 轻量RAG模块 + BGE-small-zh向量模型存储证监会发布的理财科普公开文档，实现精准问答检索
交互层Streamlit 1.35快速搭建Web对话界面，支持账单图表可视化展示
数据处理层Pandas 2.2 + Pyecharts 2.0负责消费数据统计、占比图/趋势图生成

架构说明：整体采用经典的Agent分层架构，用户对话请求首先进入大模型推理层，判断请求类型：若为记账/查账/分析类需求，则调用对应工具操作SQLite数据库，返回结构化结果后由大模型整理为自然语言；若为理财知识类问题，则通过RAG模块检索知识库相关片段，生成带溯源的科普回答；所有数据计算、图表生成都在本地完成，仅自然语言理解与生成环节调用大模型API，兼顾响应速度与数据安全性。

核心代码骨架

# 核心模块：工具定义与Agent初始化 文件名: finance_agent.py
from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.tools import tool
from langchain_community.chat_models import ChatZhipuAI
from sqlalchemy import create_engine
import pandas as pd
# 初始化本地数据库连接
engine = create_engine("sqlite:///finance_bot.db")
# 初始化大模型，替换为自己的API Key
llm = ChatZhipuAI(model="glm-4-air", temperature=0.1, zhipuai_api_key="YOUR_API_KEY")
# 工具1：记账工具，自动提取交易字段写入数据库
@tool
def add_transaction(amount: float, category: str, trade_type: str, trade_time: str = None, note: str = "") -> str:
    """
    记录一笔收支交易，当用户提到花了钱、收了钱、记一笔账时调用
    :param amount: 交易金额，单位为元，必须为数字
    :param category: 交易分类，可选：餐饮、通勤、娱乐、工资、理财、其他
    :param trade_type: 交易类型，收入/支出
    :param trade_time: 交易时间，格式为YYYY-MM-DD HH:MM，默认取当前时间
    :param note: 交易备注
    """
    import datetime
    trade_time = trade_time or datetime.datetime.now().strftime("%Y-%m-%d %H:%M")
    df = pd.DataFrame([{"amount": amount, "category": category, "trade_type": trade_type,
                        "trade_time": trade_time, "note": note}])
    df.to_sql("transactions", engine, if_exists="append", index=False)
    return f"已记录{trade_type}{amount}元，分类：{category}"
# 工具2：账单分析工具，查询指定周期消费数据
@tool
def analyze_bill(period: str = "month") -> dict:
    """
    分析指定周期的收支情况，当用户问我这个月花了多少、消费占比时调用
    :param period: 查询周期，可选week/month/quarter
    """
    sql = f"SELECT category, SUM(amount) as total FROM transactions WHERE trade_type='支出' AND trade_time >= date('now', 'start of {period}') GROUP BY category"
    result = pd.read_sql(sql, engine).to_dict("records")
    total_expense = sum([i["total"] for i in result])
    return {"total_expense": total_expense, "category_detail": result}
# 初始化Agent
tools = [add_transaction, analyze_bill]
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是FinanceBot理财顾问，只回答记账、预算、理财科普相关问题，不提供投资建议，调用工具后再回复用户"),
    ("user", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])
agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
if __name__ == "__main__":
    # 测试对话
    print(agent_executor.invoke({"input": "今天中午吃外卖花了35块，帮我记一下"})["output"])

运行步骤

  1. 环境准备：本地安装Python 3.10+，执行命令创建虚拟环境并激活：python -m venv venv && source venv/bin/activate（Windows系统执行venv\Scripts\activate）
  2. 安装依赖包：执行命令安装所有依赖：pip install langchain==0.2.11 langchain-community==0.2.10 sqlalchemy==2.0.31 pandas==2.2.2 streamlit==1.35.0 pyecharts==2.0.4 zhipuai==2.0.1
  3. 申请大模型API Key：前往智谱AI开放平台注册账号，获取GLM-4-Air的API Key，替换finance_agent.py中的YOUR_API_KEY字段
  4. 初始化数据库：首次运行执行python -c "from finance_agent import engine; from sqlalchemy import text; with engine.connect() as conn: conn.execute(text('CREATE TABLE IF NOT EXISTS transactions (id INTEGER PRIMARY KEY AUTOINCREMENT, amount FLOAT, category TEXT, trade_type TEXT, trade_time TEXT, note TEXT)')); conn.commit()"完成表结构创建
  5. 启动Web界面：在项目根目录创建app.py，导入agent_executor并编写Streamlit对话逻辑，执行命令streamlit run app.py，浏览器自动打开http://localhost:8501即可开始对话
  6. （可选）导入知识库：将证监会发布的《投资者教育手册》等公开理财科普PDF放入./knowledge目录，执行python build_rag.py完成向量库构建，即可启用理财问答功能

扩展思路

  • 多平台账单导入：开发支付宝、微信账单CSV解析模块，支持一键导入历史账单，无需手动补录过往收支数据，大幅降低用户使用门槛
  • 预算动态调整：接入本地城市公开的居民消费支出统计数据，结合用户收入水平、负债情况动态调整各分类预算阈值，给出更贴合实际的建议
  • 理财收益计算工具：增加定期存款、货币基金、国债等低风险产品的收益计算工具，用户输入本金、期限、利率即可自动计算到期收益，对比不同产品的收益差异
  • 敏感信息保护：增加本地敏感词识别模块，对银行卡号、支付密码等信息做本地脱敏，不上传到大模型接口，进一步提升财务数据安全性

小结与练习

项目收获

  1. 掌握LangChain工具调用的核心开发逻辑，理解Agent“感知-决策-执行”的运行流程，能够独立开发垂直领域的大模型工具类应用
  2. 掌握轻量RAG知识库的搭建方法，能够针对专业领域文档做检索增强，避免大模型生成金融类内容时出现幻觉
  3. 掌握金融类数据的结构化处理与可视化方法，理解个人理财场景的用户核心需求，能够平衡功能实用性与数据安全性

动手练习

  1. 为现有Agent新增set_budget工具，支持用户设置单月各分类的预算额度，当用户查询账单时自动对比预算，提示超支分类与超支比例
