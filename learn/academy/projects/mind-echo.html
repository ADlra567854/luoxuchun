07 号毕业设计：MindEcho 心声回响

当代人情绪记录常陷入“写了就忘、倾诉断层”的困境，通用大模型缺乏长期记忆无法提供连续心理支持。本项目带你从零搭建带长期记忆的心理陪伴Agent，掌握RAG记忆管理、情绪识别、Agent编排的落地能力。

项目简介

MindEcho 心声回响是一款面向个人用户的轻量心理健康陪伴Agent，核心定位是“不会遗忘的情绪树洞”。区别于通用聊天机器人单次会话无上下文、传统日记工具仅做存储无反馈的痛点，它会自动沉淀用户所有情绪记录、对话内容到长期记忆库，在每次交流时主动关联历史情绪状态，给出有上下文温度的回应，同时自动生成情绪趋势报告，帮助用户觉察长期情绪变化，无数据泄露风险，完全本地化部署可作为个人专属情绪陪伴工具。

功能特性

  • 多模态情绪记录：支持文字、语音转文字输入，自动识别输入内容的情绪效价（积极/中性/消极）、情绪标签（焦虑/愉悦/低落等12类细分情绪），自动打上时间戳存入记忆库
  • 长期记忆陪伴对话：基于用户历史情绪记录、过往对话片段做上下文关联，回应时主动提及用户之前提到的重要事件（如考试、家人纪念日、长期困扰的问题），避免通用AI的“失忆感”
  • 情绪危机主动干预：当识别到用户表述中存在自伤、极端负面情绪关键词时，自动触发干预流程，推送本地心理援助热线、预设的情绪调节引导语，第一时间给出支持
  • 周/月情绪报告生成：自动聚合周期内的情绪标签分布、高频困扰关键词、情绪波动峰值时间点，生成可视化的情绪趋势报告，附带可落地的情绪调节小建议
  • 隐私本地化存储：所有用户对话、记忆数据、情绪标签均存储在本地向量库，默认不上传任何第三方服务，支持一键导出/清空所有个人数据
  • 情绪唤醒引导：当用户连续3天以上无记录时，结合过往用户容易产生情绪波动的场景（如加班、周末独处），主动发送温和的唤醒问候，引导用户抒发情绪。

技术架构

组件技术选型作用
大模型推理层Qwen2-7B-Instruct（本地部署）/ 通义千问API（可选）负责情绪识别、对话生成、报告总结的核心推理，本地部署保障隐私
记忆存储层Chroma 向量数据库 + SQLite 结构化库Chroma存储对话、记录的语义向量做长期记忆检索；SQLite存储情绪标签、时间戳、统计数据等结构化信息
记忆检索层BGE-small-zh 向量模型 + LangChain 检索链对用户输入做语义编码，按时间衰减、情绪相关度权重召回Top5相关历史记忆片段
交互层Streamlit + OpenAI-Whisper-smallStreamlit搭建Web交互界面；Whisper实现本地语音转文字输入
Agent编排层LangGraph编排情绪识别、记忆检索、危机判断、回应生成、记忆存储的全流程节点

架构说明：整体采用分层解耦设计，用户输入首先进入LangGraph编排的工作流：第一步先做情绪识别与危机关键词检测，若触发危机阈值直接走干预分支；若为正常输入则调用检索层从Chroma中召回关联历史记忆，将记忆片段+当前输入拼接成提示词传入大模型生成回应，最后将本次对话的语义向量、情绪标签分别写入Chroma和SQLite，完成一次完整交互。所有组件均支持本地部署，不需要公网环境即可运行。

核心代码骨架

# 核心Agent工作流编排（基于LangGraph）
from langgraph.graph import StateGraph, END
from langchain_core.messages import HumanMessage, AIMessage
from utils.emotion import detect_emotion, check_crisis
from utils.memory import retrieve_memory, save_memory
from utils.llm import generate_response
from typing import TypedDict, List
# 定义Agent状态结构
class MindEchoState(TypedDict):
    user_input: str
    emotion_tag: str
    emotion_score: float
    related_memories: List[str]
    is_crisis: bool
    response: str
    chat_history: List
def emotion_detect_node(state: MindEchoState):
    """情绪识别节点：识别情绪标签、检测危机信号"""
    tag, score = detect_emotion(state["user_input"])
    is_crisis = check_crisis(state["user_input"])
    return {"emotion_tag": tag, "emotion_score": score, "is_crisis": is_crisis}
def memory_retrieve_node(state: MindEchoState):
    """记忆检索节点：按情绪相关度+时间权重召回历史记忆"""
    memories = retrieve_memory(query=state["user_input"], top_k=5, time_decay=0.9)
    return {"related_memories": memories}
def response_generate_node(state: MindEchoState):
    """回应生成节点：拼接记忆+历史对话生成有温度的陪伴回应"""
    if state["is_crisis"]:
        # 触发危机干预模板
        resp = "我感受到你现在正经历很难熬的时刻，全国心理援助热线是400-161-9995，你可以试着慢慢深呼吸，我一直在这里陪着你。"
    else:
        resp = generate_response(
            user_input=state["user_input"],
            memories=state["related_memories"],
            history=state["chat_history"],
            emotion=state["emotion_tag"]
        )
    return {"response": resp}
def memory_save_node(state: MindEchoState):
    """记忆存储节点：将本次对话写入向量库和结构化库"""
    save_memory(
        user_msg=state["user_input"],
        ai_msg=state["response"],
        emotion_tag=state["emotion_tag"],
        emotion_score=state["emotion_score"],
        timestamp=datetime.now().isoformat()
    )
    new_history = state["chat_history"] + [HumanMessage(content=state["user_input"]), AIMessage(content=state["response"])]
    return {"chat_history": new_history}
# 构建工作流
workflow = StateGraph(MindEchoState)
workflow.add_node("emotion_detect", emotion_detect_node)
workflow.add_node("memory_retrieve", memory_retrieve_node)
workflow.add_node("response_generate", response_generate_node)
workflow.add_node("memory_save", memory_save_node)
# 定义流转规则：情绪识别后直接到记忆检索，不需要分支判断（危机判断在生成节点处理）
workflow.set_entry_point("emotion_detect")
workflow.add_edge("emotion_detect", "memory_retrieve")
workflow.add_edge("memory_retrieve", "response_generate")
workflow.add_edge("response_generate", "memory_save")
workflow.add_edge("memory_save", END)
mind_echo_agent = workflow.compile()

运行步骤

  1. 环境准备：安装Python 3.10+版本，创建虚拟环境并激活，执行pip install langgraph langchain chromadb streamlit openai-whisper plotly transformers torch sentence-transformers安装所有依赖库。
  2. 模型下载：若使用本地大模型，执行huggingface-cli download Qwen/Qwen2-7B-Instruct --local-dir ./models/qwen2-7b下载对话模型，同时下载BAAI/bge-small-zh向量模型、openai/whisper-small语音模型到本地models目录。
  3. 初始化数据库：在项目根目录执行python init_db.py，脚本会自动创建Chroma向量库目录、SQLite数据表（情绪记录表、对话历史表、用户配置表）。
  4. 配置参数：复制.env.example文件重命名为.env，若使用API版本则填写DASHSCOPE_API_KEY，若使用本地模型则配置MODEL_PATH=./models/qwen2-7b，设置DEVICE=cuda（有N卡）或DEVICE=cpu。
  5. 启动服务：在项目根目录执行streamlit run app.py --server.port 8501，服务启动后浏览器自动打开http://localhost:8501即可进入交互界面。
  6. 初始化引导：首次进入时按照页面提示完成初始设置（昵称、初始情绪状态），即可开始使用情绪记录、对话陪伴功能，在侧边栏可查看历史情绪报告。
  7. 可选配置：若需要开启主动提醒功能，额外执行pip install schedule，运行python reminder.py即可在后台启动定时提醒进程。

扩展思路

  • 多模态情绪感知升级：接入本地摄像头的表情识别模块（使用FER2013预训练模型），结合用户输入文字、语音语调、微表情多维度判断情绪状态，提升情绪识别准确率，避免文字表述的情绪伪装偏差。
  • 个性化CBT干预模块：在记忆库中沉淀用户常见的认知扭曲模式（如灾难化思维、非黑即白），当识别到对应思维模式时，自动引导用户做CBT认知解离练习，比如三栏笔记法（自动思维-认知扭曲-理性回应），从被动陪伴升级为主动引导。
  • 亲友授权联动：增加加密授权通道，用户可选择将极端情绪预警信息加密推送给指定紧急联系人，同时支持用户自定义安全联系人、预警触发阈值，避免危机情况无人知晓。
  • 记忆权重动态优化：基于用户对每次回应的反馈（有用/没用、是否戳中记忆点），动态调整记忆检索的权重参数，对用户高频提及、反馈相关度高的记忆片段提升召回优先级，让长期记忆更贴合用户个人认知。

小结与练习

核心收获

  1. 掌握带长期记忆的Agent设计方法，理解如何通过“检索-增强-存储”的闭环解决大模型上下文窗口有限、会话失忆的问题，可复用到各类个人专属Agent场景。
  2. 掌握心理健康场景的Agent安全设计逻辑，理解危机识别、隐私保护在垂直领域Agent中的优先级，学会在生成流程中加入安全护栏避免有害回应。
  3. 掌握LangGraph工作流编排方法，能够将复杂的多步骤Agent逻辑拆分为独立节点，通过可视化的流转规则实现灵活的流程调整，降低代码耦合度。

动手练习

  1. 基础练习：在现有代码的记忆检索逻辑中加入时间衰减因子，实现越近的记忆召回权重越高，测试对比加入前后对3个月前的历史事件、最近3天事件的回应关联度差异。
  2. 进阶练习：在情绪报告模块新增“情绪触发点统计”功能，从历史记录中提取用户负面情绪出现时的高频共现场景（如加班、熬夜、某类社交场景），在报告中给出场景触发提示。
