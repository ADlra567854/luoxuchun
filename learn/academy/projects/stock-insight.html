01 号毕业设计：StockInsight 股票分析

个人投资者在股票分析中常面临数据获取分散、K线解读门槛高、研报信息过载的痛点，本项目通过构建端到端智能分析工具，帮你掌握金融数据爬取、可视化分析与大模型Agent开发的全流程能力，可直接复用为个人投研辅助工具。

项目简介

StockInsight 股票分析是面向个人投资者的轻量级智能投研辅助工具，聚焦A股/港股/美股的公开市场数据整合，解决传统行情软件信息杂、分析维度单一、缺乏自然语言交互能力的问题。项目以Python为核心开发语言，整合免费公开数据源与开源大模型能力，无需付费API即可完成从数据拉取、可视化分析到智能洞察生成的全链路操作，最终交付可本地运行的Web交互应用，所有代码开源可修改，适合作为金融科技方向的入门级毕业设计项目。

功能特性

  • 多市场股票基础数据查询：支持A股、港股、美股的实时行情、历史交易数据、上市公司基本信息、财务指标一键查询，自动适配不同市场的代码规则
  • 交互式K线分析：内置日/周/月线切换，自动叠加MA5/MA10/MA20/MA60均线、MACD、KDJ、BOLL等常用技术指标，支持鼠标悬停查看单日量价详情
  • 智能投资洞察生成：对接开源大模型，自动结合量价走势、技术指标信号、近期行业新闻生成结构化分析报告，包含多空信号提示与风险预警
  • 自选股持仓追踪：支持本地自选股列表管理，自动计算持仓盈亏、当日涨跌幅排名，支持设置涨跌幅阈值提醒
  • 市场热点板块轮动分析：每日自动抓取板块涨跌幅数据，生成近7日板块热度变化曲线，标注资金流入流出排名靠前的赛道
  • 历史行情回测小工具：支持简单的均线策略、MACD策略回测，自动计算策略收益率、最大回撤、胜率等核心回测指标

技术架构

组件技术选型作用
数据采集层akshare、requests拉取股票行情、财务数据、板块资金、新闻资讯等公开金融数据，无需付费API密钥
数据处理层pandas、numpy完成行情数据清洗、指标计算、时间序列对齐、回测逻辑实现
可视化层pyecharts、streamlit生成交互式K线图、指标图、热力图，搭建低代码Web交互界面，无需前端开发经验
智能分析层Qwen-7B-Chat（本地部署）/ 通义千问API、langchain构建股票分析Agent，将结构化数据转化为自然语言洞察，支持自然语言提问查询
本地存储层sqlite3存储自选股列表、用户持仓配置、历史查询缓存，降低重复数据拉取频率

架构说明：项目采用分层解耦设计，数据层统一封装akshare的多源数据接口，向上提供标准化的DataFrame格式输出；业务逻辑层分离指标计算、回测、洞察生成三个独立模块，各模块通过标准数据结构交互；展示层基于Streamlit实现单页应用，所有组件通过Python代码声明式生成，支持本地一键启动，也可部署到Streamlit Community Cloud实现公网访问；智能分析层采用可插拔设计，既支持本地部署开源大模型保证数据隐私，也可切换为云端API降低本地硬件要求。

核心代码骨架

# 1. 数据获取与指标计算模块：stock_data.py
import akshare as ak
import pandas as pd
def get_stock_hist_data(symbol: str, period: str = "daily", start_date: str = "20230101") -> pd.DataFrame:
    """获取股票历史行情数据并计算技术指标
    :param symbol: 股票代码，A股如600519，美股如AAPL，港股如00700
    :param period: 周期，支持daily/weekly/monthly
    :param start_date: 起始日期，格式YYYYMMDD
    """
    # 拉取原始行情数据
    if symbol.isdigit() and len(symbol) == 6: # A股适配
        df = ak.stock_zh_a_hist(symbol=symbol, period=period, start_date=start_date, adjust="qfq")
    # 计算均线指标
    df["MA5"] = df["收盘"].rolling(5).mean()
    df["MA10"] = df["收盘"].rolling(10).mean()
    df["MA20"] = df["收盘"].rolling(20).mean()
    # 计算MACD指标
    ema12 = df["收盘"].ewm(span=12, adjust=False).mean()
    ema26 = df["收盘"].ewm(span=26, adjust=False).mean()
    df["DIF"] = ema12 - ema26
    df["DEA"] = df["DIF"].ewm(span=9, adjust=False).mean()
    df["MACD"] = (df["DIF"] - df["DEA"]) * 2
    return df.dropna()
# 2. 智能洞察生成模块：agent.py
from langchain.llms import Ollama
from langchain.prompts import PromptTemplate
def generate_insight(df: pd.DataFrame, stock_name: str) -> str:
    """基于最近30个交易日数据生成投资洞察"""
    recent_data = df.tail(30)[["日期","收盘","涨跌幅","MA5","MA20","MACD"]].to_string(index=False)
    # 提示词模板，约束输出结构
    prompt = PromptTemplate.from_template("""
    你是专业股票分析师，基于以下{stock_name}近30个交易日的行情数据生成结构化分析：
    1. 近期走势总结（不超过100字）
    2. 技术指标信号（明确多/空/震荡判断）
    3. 风险提示（至少1条）
    行情数据：
    {data}
    """)
    # 调用本地部署的Qwen大模型，需提前启动ollama服务
    llm = Ollama(model="qwen:7b-chat", temperature=0.1)
    return llm(prompt.format(stock_name=stock_name, data=recent_data))

运行步骤

  1. 环境准备：安装Python 3.9~3.11版本（3.12以上版本部分依赖存在兼容问题），执行pip install akshare==1.12.85 pandas numpy pyecharts streamlit langchain ollama安装所有依赖库
  2. 大模型环境配置（可选本地部署）：访问ollama官网下载对应系统安装包，执行ollama run qwen:7b-chat拉取并启动开源大模型服务；若本地硬件不足，可申请通义千问/豆包API密钥替换本地模型调用逻辑
  3. 项目初始化：创建项目目录，新建app.py、stock_data.py、agent.py三个核心文件，将上述核心代码骨架复制到对应文件中
  4. 编写Web入口：在app.py中导入Streamlit组件，添加股票代码输入框、周期选择下拉框、K线展示区域、洞察生成按钮，调用pyecharts的Kline组件渲染交互式K线图
  5. 本地启动测试：在项目目录下执行streamlit run app.py，浏览器会自动打开http://localhost:8501 访问应用，输入股票代码（如600519贵州茅台）测试数据拉取与K线展示功能
  6. 功能验证：点击「生成投资洞察」按钮，检查大模型返回的分析报告是否符合数据事实，测试自选股添加、板块热度查询功能是否正常
  7. （可选）公网部署：将代码上传到GitHub，关联Streamlit Community Cloud，无需服务器即可实现公网访问，可分享给他人使用

扩展思路
