AI 工具 · 如何使用

这一页只回答一个问题：这些 AI 工具到底怎么用。 8 款编程助手怎么选、WorkBuddy 从领积分到连专家怎么走、22 款开源工具一行命令怎么跑起来—— 每款都给官方出处和最简上手步骤，点开就能照着做，不用在十几个页面之间来回翻。

三种工具放一起讲：编程助手（帮你写代码）、WorkBuddy（办公 + 代码的全场景工作台）、 开源工具（自己搭的本地能力）。它们不是同一类，但都是"会用才有用"的工具， 所以收在一页按场景展开。主观评分均来自第三方实测、仅供参考；定价与入口以各产品官网当期页面为准。

二、WorkBuddy · 从领积分到连专家

先辨明同名：这里只讲腾讯 WorkBuddy（官网 workbuddy.cn / 文档 codebuddy.cn）。 另有一家国外公司 workbuddy.com 做现场服务管理软件，与腾讯 WorkBuddy 无关。 它是"全场景工作台"，覆盖办公文档、数据分析、PPT、代码等，与上面"专注写代码"的助手不完全同类； 积分额度与入口会随版本档期调整，一切以你账号内当期页面为准。
① 快速上手：五步走完一个任务
步骤做什么要点
1 建任务选工作模式、填任务内容、补充上下文描述目标即可，不用预先拆步骤
2 管任务侧边栏查看任务列表、按状态筛选、继续处理任务按文件夹分组，支持搜索
3 对话对话区持续追问、上传文件、用顶部操作多轮追加需求，不必一次说全
4 看结果右侧结果区切换产物、全部文件、变更、预览交付的是可验收成果，不只是文字
5 复用把成果存回资料库，供后续查找调用形成"越用越顺手"的积累

③ 查资料库：让资料进任务、成果回资料库

资料库可直接上传本地文件、办公文档、多媒体文件，也支持剪藏网页链接。 要让 Agent 基于已有资料工作时，在资料库里选空间或文档、添加到任务； 任务产出的新成果再保存回资料库，供后续查找调用。容量按会员版本分档，可在侧边栏底部看容量条。

来源：WorkBuddy 官方《资料库》原文 ↗。核验 2026-11-16。

④ 连接专家 / 专家团 / 技能 / 连接器
能力官方定义什么时候用
专家（Agent 型）"人设 + 方法论 + 工具链"的角色切换机制有明确单点问题，想让 AI 用该领域视角解决
专家团（Team 型）多位专家分工协作，团长自动拆解、并行执行、整合交付任务复杂、需要多角色配合
技能（Skill）提供执行能力，让 AI 能做某件事需要 AI 具备某种具体工具能力
连接器接入第三方服务，让 WorkBuddy 访问外部数据并执行操作要连通外部服务/数据源时

怎么召唤：打开专家中心 → "专家·技能·连接器" → 按行业分类浏览 → 看能力介绍和任务示例 → 点"召唤专家"进入对话 → 描述需求。 召唤后它会从该专家的引导提示词里随机选一条开场，所以同一专家每次开场可能不同。

权限边界（官方明确）：专家本身不主动获取系统权限，只处理你主动提供的对话与上传文件； 只有配备 Skill / MCP 时才会在你授权下间接访问文件或外部服务。装技能优先选来源、更新记录、权限说明清楚的。

来源：WorkBuddy 官方《专家 · 专家中心》原文 ↗。核验 2026-11-16。

⑤ 把常用提示词方法固化下来

很多人问"怎么让 WorkBuddy 记住我的提示词"。官方并没有一个叫"记忆提示词"的开关； 真正可复用的做法是把反复用的提示词方法沉淀成专家或技能：在"我的专家"里创建一个属于你的专家， 把固定的人设、方法论、任务示例写进去，下次直接召唤它，就不用每次重打一大段。资料库里沉淀的文档也能作为任务上下文被反复读取。

据官方文档"专家是角色切换机制""在我的专家创建属于你的专家""资料库供检索复用并作为任务上下文"归纳，非某一独立功能名。核验 2026-11-16。

三、开源工具 · 22 款一命令上手

全部为真实开源项目，地址与命令已核实。每条直达官方 GitHub / 官网，本站不托管安装包；命令在不同系统/版本可能需微调，以项目官方 README 为准。

1 · 本地跑大模型

无需联网、无需 API Key，权重本地跑。轻量用 Ollama 起步，追求吞吐量上 vLLM / SGLang。

Ollama推理引擎

一行命令下载并运行本地开源大模型（Llama / Qwen / DeepSeek 蒸馏版等），门槛最低。

GitHubollama/ollama官网 ↗
curl -fsSL https://ollama.com/install.sh | sh ollama run deepseek-r1:7b
最简上手：装好后直接 ollama run deepseek-r1:7b，终端即开即聊；Windows/macOS 用官网安装包。
免费本地显卡：可选（CPU 可跑）

llama.cpp轻量推理

纯 C/C++ 大模型推理引擎，GGUF 量化后几乎任何设备（含 CPU、苹果芯片）都能跑。

GitHubggml-org/llama.cpp
git clone https://github.com/ggml-org/llama.cpp cd llama.cpp && cmake -B build && cmake --build build --config Release
最简上手：下载 GGUF 模型后运行 ./llama-cli -m model.gguf -p "你好"。
免费本地显卡：可选（CPU 即可）

LM Studio图形界面

桌面图形应用，点几下就能搜索、下载并运行本地模型，全程无需命令行。

GitHublmstudio-ai/lms官网 ↗
winget install ElementLabs.LMStudio
最简上手：官网下载安装包 → 搜索模型 → 下载 → 直接对话。
免费（个人）本地显卡：可选（建议独显）

vLLM生产推理

面向生产的高吞吐 LLM 推理服务引擎，兼容 OpenAI API，适合把模型部署成服务。

GitHubvllm-project/vllm
pip install vllm vllm serve Qwen/Qwen2.5-7B-Instruct
最简上手：起服务后浏览器打开 http://localhost:8000，用 OpenAI 兼容接口调用。
免费本地显卡：需要（NVIDIA）

SGLang极速推理

新一代 LLM / VLM 推理服务框架，吞吐高、支持结构化输出，常用于生产部署。

GitHubsgl-project/sglang
pip install "sglang[all]" python -m sglang.launch_server --model Qwen/Qwen2.5-7B-Instruct
最简上手：起服务后按 OpenAI 兼容格式请求 http://localhost:30000/v1。
免费本地显卡：需要（NVIDIA）

3 · 本地语音

Whisper 负责"听懂"，Piper / Bark 负责"说话"，全部离线免费。

Whisper语音识别

OpenAI 开源语音识别模型，多语言转文字 + 翻译，本地离线可用，做字幕神器。

GitHubopenai/whisper
pip install openai-whisper whisper audio.mp3 --language Chinese
最简上手：装好后 whisper 文件.mp3 即可输出带时间轴的转写结果。
免费本地显卡：可选（CPU 可跑）

Piper轻量合成

轻量级本地 TTS，速度快、能跑树莓派，适合离线朗读与嵌入式设备。

GitHubrhasspy/piper
pip install piper-tts echo "你好" | piper --model zh_CN-huayan-medium.onnx --output_file out.wav
最简上手：下载中文 ONNX 语音模型 → 命令行合成 WAV。
免费本地显卡：不需要（纯 CPU）

Bark情感合成

Suno 开源多语言 TTS，能生成带语气、笑声甚至音乐感的自然语音。

GitHubsuno-ai/bark
pip install suno-bark
最简上手：几行 Python 调用 generate_audio 生成语音；CPU 很慢，建议用 GPU。
免费本地显卡：强烈建议（CPU 极慢）

4 · Agent / 工作流

代码框架（LangChain / AutoGen / CrewAI）+ 可视化平台（Dify / n8n），无需显卡，走 API 即可。

LangChain应用框架

最流行的 LLM 应用开发框架，把模型、工具、记忆、检索串成链与 Agent。

GitHublangchain-ai/langchain

免费本地显卡：不需要

6 · 训练 / 微调

从 Transformers 加载预训练模型，用 PEFT/LoRA 低显存微调，再用 DeepSpeed 加速大规模训练。

Transformers模型库

Hugging Face 最广泛使用的模型库，统一加载、微调、推理数千种预训练模型。

GitHubhuggingface/transformers
pip install transformers
最简上手：pipeline("sentiment-analysis")("I love AI") 一行跑通推理。
免费本地显卡：可选（训练建议）

PEFT / LoRA高效微调

高效参数微调库，用 LoRA 只训练极小部分参数，低显存也能微调大模型。

GitHubhuggingface/peft

最简上手：配合 Transformers 用 LoraConfig 挂载后微调。
免费本地显卡：建议（显存大幅降低）

DeepSpeed分布式训练

微软开源深度学习优化库，分布式训练 / 推理加速，可训练超大模型。

GitHubmicrosoft/DeepSpeed
pip install deepspeed

免费本地显卡：需要（多卡加速）

四、按你的情况选，不看排名

预算有限 / 学生党

先免费后付费

TRAE 基础版免费、中文需求理解准，与 VS Code 同源可一键导入配置；再搭通义灵码补中文场景。想本地跑模型就用 Ollama + LM Studio，CPU 也能起步。

副业快速交付

Builder → Work → 补全

用 TRAE Builder 从需求直接生成项目骨架，Work 模式扛 CRUD 主力，再配 Copilot / Cursor 做日常补全；要搭后台就上 Dify，可视化连工作流。

复杂推理 / 大仓重构

深度 + 成本自控

Claude Code 在代码审查、复杂 Bug 排查上优势明显，但按用量计费要自己把控。常见用法是"Cursor 写日常 + Claude Code 干重活"。

数据私密 / 企业合规

本地 + 私有化

数据不出本机：Ollama 本地跑模型 + Open WebUI / LobeChat 做界面；企业场景优先支持私有化的通义灵码企业版、TRAE 企业版，权益以官网当期为准。
