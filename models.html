Chapter 02

DeepSeek 时刻：从 R1 到 V4.1 的路线延续

R1 当年证明的命题——顶级智能可以不靠天价算力堆出来——在 2026 年被 V4 家族继续执行：架构换代、原生多模态、1M 上下文，以及全线的峰谷半价。

2026.04.24 · V4 双型号上线

V4-Pro 与 V4-Flash 同时开放 API

DeepSeek 在 4 月 24 日把 API 换代到 V4：deepseek-v4-pro 与 deepseek-v4-flash 同时支持 OpenAI ChatCompletions 与 Anthropic 接口， 旧型号名 deepseek-chat / deepseek-reasoner 进入三个月下线倒计时。这一步把「换模型不换代码」变成默认体验。

2026.08.13 · V4-Pro 正式可用

Agent 能力大幅强化 + 原生 Responses API

V4-Pro 的 GA 版本重点提升生产环境下的 Agent 能力，并原生支持 OpenAI Responses API、针对 Codex 做了适配； 思考模式引入 low / high / max 三档强度。官方同时宣布采用峰谷计价，谷值为峰值半价。

2026.09.10 · V4.1-Flash

新架构 + 原生多模态视觉理解

V4.1-Flash 被称为「新架构家族中最小的模型」，特点是原生多模态视觉理解、更高吞吐与更大的能力上限； 官方给出的基准为 GPQA Diamond 90.9、Codeforces Rating 3471、Terminal-Bench 2.1 90.6。价格同步下调。

2026.10.17 · V4.1-Flash-1017

同样的价格，更好的「性能—成本」帕累托点

1017 版本在不改调用方式与价格的前提下提升基准（HLE 42.6、Terminal-Bench 4.0 42.3、DeepSWE v1.1 77.0）， 并缩短任务运行时长与输出长度，让单任务成本进一步下降——这正是 2026 年竞争的真实单位：不是每 token 多少钱，而是每件事多少钱。

Chapter 04

给创作者 / 个人 IP 的选型建议

没有「最好」的模型，只有「最合适」的模型。选型公式：任务匹配 × 单任务成本 × 隐私与可控性。

长文写作 / 中文创作 DeepSeek / Qwen3.8-Max / Kimi

写公众号、小红书、知乎、小说、脚本，中文语感和成本是首要考量。DeepSeek V4.1 Flash 输入 $0.30 起，Qwen3.8-Max 多模态可直接读图写稿， Kimi K3.1 Pro 吃超长资料。三家合计覆盖「便宜量产 → 图文一体 → 超长上下文」的完整链路。

性价比首选

写代码 / 构建工具 Claude Opus 5.5 / GLM-5.3

复杂工程、长代码库重构首选 Claude Opus 5.5（Terminal-Bench 4.0 66.4%，官方称在 FrontierCode 上以约 20% 的单任务成本胜过 GPT-6 Astra）； 预算敏感或需要开源可自托管，用 GLM-5.3（$1.4 / $4.4，编码较 5.2 提升 50%）。

工程能力优先

读图 / 读视频 / 多模态 Gemini 4 Argon / Qwen3.8-Max / 豆包 Seed2.1

要理解图片、视频、音频并产出结构化内容，Gemini 4 Argon 原生多模态 + 1M 统一额度最省心；Qwen3.8-Max 官方称 Vision Arena 第 2； 豆包 Seed2.1 官方 Model Card 的 VideoMME 为 89.2，长视频理解是其主场。

多模态首选

深度推理 / 选题策划 DeepSeek V4-Pro / Claude Opus 5.5

需要「想清楚」的活——选题分析、剧情逻辑校验、商业策划、数学推导：DeepSeek V4-Pro 的 HLE 为 42.7（with tools 60.0），成本远低于闭源； 追求上限再上 Opus 5.5（HLE 67.7% with tools）。

推理质价比
性价比怎么算

算单任务成本，不算「每 token 单价」

2026 年厂商都在「省 token」上做文章：Opus 5.5 官方称同一任务总成本比 Opus 5 低约 40%；DeepSeek V4.1-Flash-1017 直接缩短输出长度。 同一个任务跑两遍截图对比账单，比背价格表有用。

「强模型定调 + 便宜模型量产」

用贵模型打磨模板、定风格、审关键稿，用国产模型跑批量初稿与改写。80% 的活儿交给便宜模型，20% 的精品交给顶配—— 这条 2026 年依然成立，只是便宜模型的「可用下限」比过去高得多。

善用缓存与峰谷时段

DeepSeek 缓存命中低至输入的 1/50 量级（$0.006 峰值），谷值为峰值半价；Kimi K3 系列缓存命中 ¥1.30、TTL 默认 5 分钟； Claude 缓存读 $0.20。把「设定文档 / 风格参考 / 知识库」固定放上下文命中缓存，是最直接的降本手段。

自部署 vs 云 API

开源 + 本地自部署

适合：隐私敏感数据、稳定可控、长期高频、有硬件/技术能力的创作者与团队。
路径：Ollama / vLLM 拉取 GLM-5.3、DeepSeek V4.1、Qwen3.8-Max 或 Kimi K3.1 Pro 权重（后者 11-04 前发布）； 1M 上下文对显存要求高，实测前先按短上下文降级跑通。

隐私 + 长期成本

云 API / 官方服务

适合：快速上手、弹性用量、需要最新最强模型的创作者。
路径：DeepSeek 官方 API（兼容 OpenAI / Anthropic 格式）、阿里云百炼（Qwen3.8-Max）、 Z.AI、Kimi 开放平台、火山方舟（Seed2.1）；海外三家按需接入。零维护、按量付费。

AI 工具 · 如何使用（好多款，点开照着做）

大模型负责「想得深」，工具负责「干得完」。这一块把 WorkBuddy + 8 款编程助手 + 12 款办公/知识/通用工具 收在一起， 编程工具按 7 种情况对号入座、通用工具按 9 类任务直接查表，每款给一句定位、最简上手和官方入口。第三方主观评分均标来源、定价与入口以各产品官网当期页面为准； 本站不托管任何第三方安装包、不代领积分、不提供生成式 AI 服务。

先看一个：WorkBuddy 从建任务到连专家
先辨明同名：这里只讲腾讯 WorkBuddy（官网 workbuddy.cn / 文档 codebuddy.cn）。 国外另有一家 workbuddy.com 做现场服务管理软件，与腾讯 WorkBuddy 无关。 它是覆盖办公文档、数据分析、PPT、代码的全场景工作台，积分与入口会随版本档期调整，以你账号当期页面为准。

五步走完一个任务

步骤做什么要点
1 建任务选工作模式、填任务内容、补上下文描述目标即可，不用预先拆步骤
2 管任务侧边栏看列表、按状态筛选、继续处理任务按文件夹分组，可搜索
3 对话对话区持续追问、上传文件、用顶部操作多轮追加需求，不必一次说全
4 看结果右侧切换产物 / 全部文件 / 变更 / 预览交付可验收成果，不只是文字
5 复用把成果存回资料库，供后续查找调用形成「越用越顺手」的积累
② 每日领积分与成长任务（入口以当期页面为准）

左下角头像 → Buddy 加油站 → 领今日礼包；头像 → 成长计划 → 选任务 → 完成 → 回来点「领取奖励」才到账。 下列入口整理自公开实测（核对 2026-11-01），不是官方承诺，额度会变。 别向任何代领服务交出登录凭证，本站也不代领、不代持。

③ 查资料库 / ④ 连专家·专家团·技能·连接器

资料库可上传本地文件、办公文档、多媒体，也能剪藏网页；要让 Agent 基于资料工作，就把它添加到任务，产出的成果再存回资料库。 专家中心 → 按行业浏览 → 看能力与示例 → 点「召唤专家」进入对话。专家本身不主动获取系统权限，只有配了 Skill / MCP 才在你授权下访问文件。

⑤ 把常用提示词方法固化下来

官方并没有一个叫「记忆提示词」的开关；可复用的做法是把反复用的提示词方法沉淀成专家或技能——在「我的专家」里建一个专属专家，写进固定人设、方法论、任务示例，下次直接召唤。
