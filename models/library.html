「开源度」分三档，不要混用：开源 = 权重可下载且许可允许商用； 开放权重 = 权重可下载但商用条款受限（如 Llama 社区许可、Gemma 条款）； 闭源 = 仅 API 或仅私有部署授权。能不能私有化只看这一列。

这六列怎么影响选型

开源度 决定部署形态

只有「开源 + 许可允许商用」才能私有化到自己的服务器；「开放权重」商用前要读条款（多数有月活或营收门槛）。金融、医疗、政务项目通常只看前两档里的第一档。

规模 决定硬件门槛

端侧（≤4B 量化）可上手机与车机；小型 4–10B 单卡可跑；中型 10–100B 需多卡或量化；大型 100–500B 需 MoE 或 8 卡以上；超大 >500B 基本只能走 API。

时点 决定它还活着没有

超过 12 个月没有更新的型号，多半已被同厂新版本替代。榜单上看到老型号排名高，往往是因为它作为基线长期在测，不代表现在还是最好选择。
