CHAPTER 01先懂规律：2026 开源 AI 的六个共同特点

把 GitHub 热榜翻到底，规律清晰得惊人。看懂这六条，任何新项目到你手里都能三分钟看透。

1. 从"造模型"转向"造身体"。增长最快的不再是新模型，而是让模型干活的基建：DeepSeek Harness（一切皆插件）、OpenMontage（视频流水线）、各类 Skill 技能包。模型是大脑，2026 年的战场在四肢。

2. 对话即界面。主流项目统一支持 MCP 或插件机制，交互收敛为一种：自然语言下命令，Agent 调工具执行。"配置"正在消失。

3. 本地优先。Ollama、vLLM 的爆发说明隐私、零成本、离线是刚需。开源权重让"自己的模型跑在自己的机器上"成为默认。

4. OpenAI API 格式是事实标准。几乎所有推理框架都暴露 /v1/chat/completions 兼容接口——学会一次调用，换掉底层任何模型。

5. 流水线化取代单点生成。AI 视频从"生成片段"转向"组织整个生产流程"，写作、编程同理。

6. 工程纪律回潮。superpowers（26 万 star）登顶说明社区共识：让 AI 写出能维护的代码，测试、审查、知识库一个不能少。

记住公式：开源模型 + OpenAI 接口 + 插件 Agent + 本地部署 + 流水线。下面每一章都是它的具体化身，而且每一章都有真实演示。

2.1 Ollama：三条命令，本地模型开口说话

GitHub 15 万+GoMIT难度：硬件：8GB 内存起步
安装（三选一）
# Windows：官网下载 OllamaSetup.exe 双击安装  ollama.com/download

拉取模型并对话（按内存选一个）

跑完之后是什么样？真实对话长这样：

终端 · ollama run deepseek-r1:14b
你用一句话向小学生解释什么是"反向传播"。
DEEPSEEK-R1（本地 · 离线）反向传播就像投篮练习：你投出一球没进（误差），教练告诉你"力气大了、偏左了"，你就调整手腕的每个动作（每个参数）——从最后出手的手指，一路调整回脚的发力。调整亿万次之后，你就成了神射手。
全程离线、免费、数据不出本机。这就是"把 DeepSeek 装进自己电脑"的真实体验。

2.2 关键一步：把模型变成"任何软件都能用的 API"

Ollama 默认已开启 OpenAI 兼容接口（11434 端口），直接验证：
curl http://localhost:11434/v1/chat/completions -d "{\"model\":\"qwen3:8b\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}"

返回一段 JSON 就说明成功。之后任何支持"自定义 OpenAI 接口"的软件——沉浸式翻译、Obsidian、Chatbox、你自己写的 Python 脚本——把地址填成 http://localhost:11434/v1，密钥随便填，全部免费用上本地模型。

2.3 进阶实战：用 Modelfile 捏一个"人设模型"

这是大多数人不知道的 Ollama 杀器：把"模型 + 系统提示词 + 参数"打包成一个新模型。下面是真实可用的例子——捏一个只聊创作的写作助教：

三步捏人设
# 1. 新建一个文本文件，命名为 Modelfile（无后缀），内容：
FROM qwen3:8b
SYSTEM """你是「墨白」，一位毒舌但靠谱的写作助教。规则：
1. 只回答写作相关问题，其他问题礼貌拒绝
2. 每次先指出文本的 1 个最大问题，再给修改示范
3. 禁止说"挺好的"这类空话"""
PARAMETER temperature 0.8
# 2. 打包成新模型
ollama create mobai -f Modelfile
# 3. 使用
ollama run mobai
真实效果 · ollama run mobai
你帮我看看这句："今天的天气很好，我的心情也很好。"
墨白（你捏的人设）最大问题：两个"很好"是零信息量。天气好在哪里？心情好到什么程度？读者什么都看不见。修改示范："太阳把柏油路晒得发软，我踩着影子走，一路都在哼歌。"——具体画面自带情绪，不需要说"好"。
这就是"提示词工程"的落地形态：人设一旦写进 Modelfile，每次对话自动生效。你也可以用同样方法捏客服、英语老师、代码审查员——提示词就是你的产品。
硬件速查：8GB 内存 7B/8B 量化模型；16GB 14B；24GB 显存（4090 级） 32B。想跑满血 671B？那不是消费级硬件的事，用官方 API。

CHAPTER 03提示词实战：三个真实案例，输入什么、得到什么

案例 1 · 让 AI 当你的选题军师

DeepSeek-R1 · 真实提示词与输出
你的输入（直接复制可用）你是百万粉丝科技博主。围绕"普通人用 AI 赚钱"产出 5 个短视频选题。要求：标题 ≤20 字，含数字或悬念；标注目标情绪（好奇/焦虑/共鸣）；给每个选题写一句 15 字以内的开场钩子。输出为表格。
真实输出（节选）1.《我用 AI 接单，一个月赚了 4000》｜情绪：好奇+焦虑｜钩子："我没辞职，也没投资，只靠下班后两小时。"
2.《这 3 类工作，AI 已经开始抢单了》｜情绪：焦虑｜钩子："如果你是做文案的，先看完这条再睡。"
3.《宝妈用 AI 做表情包，月入过万？》｜情绪：好奇｜钩子："我亲测了 7 天，结果和想的不一样。"

拆解这条提示词为什么有效：角色（百万粉博主）+ 任务（5 个选题）+ 约束（字数、情绪、钩子）+ 格式（表格）。四件套齐全，输出质量立判高下。

案例 2 · 让 AI 写"能跑"的代码

DeepSeek · 真实提示词与输出
你的输入你是资深 Python 工程师。写一个脚本：读取当前文件夹所有 .md 文件，统计每个文件的字数，输出为 CSV（文件名,字数）。要求：处理中文编码；加注释；最后告诉我怎么运行。
真实输出（核心代码）import os, csv — 遍历 os.listdir('.') 以 encoding='utf-8' 打开 len(text) 计字 csv.writer 写入 report.csv。运行方法：保存为 count.py，终端执行 python count.py，同目录生成 report.csv。

案例 3 · 杠精编辑法：让 AI 骂你的稿子

DeepSeek-R1 · 本基地博文真实用过的工作流

CHAPTER 05应用框架：零代码拼出 AI 应用

5.1 Dify：可视化 AI 应用工厂（含真实搭建流程）

GitHub 10 万+Apache 2.0难度：
Docker 一键部署
git clone https://github.com/langgenius/dify.git
cd dify/docker && cp .env.example .env
docker compose up -d   # 打开 http://localhost
  1. 接入免费模型：设置 模型供应商 选 "OpenAI-API-compatible" 填 http://host.docker.internal:11434/v1（即你第 2 章装的 Ollama），模型名填 qwen3:8b，密钥任意。

5.2 n8n：自动化流水线（真实案例：每日 AI 日报机器人）

启动
docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

打开 http://localhost:5678，拖四个节点连起来：定时触发（每天 8:00） HTTP 抓取 10 条 AI 新闻 DeepSeek 节点总结成 300 字 邮件节点发送。保存激活后，它每天自动替你上班。

CHAPTER 13部署常见坑：踩过的人给你排雷

① 端口被占用：Address already in use

另一个程序占着 11434 / 8188 等端口。查占用：netstat -ano | findstr 11434 记下 PID 任务管理器结束；或换端口启动（Ollama 设 OLLAMA_HOST=127.0.0.1:11435）。

② 模型下载慢 / 超时

Ollama 走官方源可能慢。可先 export OLLAMA_MODELS=/你的大容量盘 换存储位置；下载慢时用 hf-mirror 拉 GGUF 再 ollama create 导入，或直接换用官方 API 过渡。

③ 显存 / 内存不足：CUDA out of memory

模型太大。换小量化版（1.5b 4b 8b 按硬件升）；关掉其它占显存的程序；Ollama 用 OLLAMA_NUM_GPU=1 控制投入 GPU 的层数，其余落 CPU。

④ Docker 拉不动 / 代理冲突

Dify / n8n 镜像拉不动：配国内镜像加速器，或设 HTTP_PROXY / HTTPS_PROXY；反之若开着代理反而报 TLS 错，先关代理再 docker pull。

⑤ 本地模型接不上 Dify

Dify 跑在 Docker 里，访问宿主机要用 host.docker.internal 而不是 localhost；模型名必须和 ollama list 完全一致（含 :8b 后缀）。

⑥ Windows 老报权限 / 路径错

PowerShell 与 Git Bash 语法有差异；路径带空格记得加引号；pip install 失败先 python -m pip install --upgrade pip。实在不行，用 WSL2 一劳永逸。

一条通用铁律：报错先读第一行英文，90% 的坑（路径、端口、权限、网络）自己就能定位；剩下 10% 复制整段报错去搜，别闭眼乱试。
