训练 / 微调分类

它解决的是哪一步

先把定位说清楚，再决定要不要装
上百个模型、SFT / LoRA / DPO 都收在一个网页里，数据集换个格式就能喂。对个人玩家来说，它把「微调」从一堆脚本参数变成了几个下拉框，是验证「我的数据到底有没有用」最快的路。大规模分布式训练不在它的射程内。

上手三步

按顺序走，卡住基本都在第一步
1
装依赖并起 webui

pip install -e . 之后 llamafactory-cli webui。跑之前确认 torch 和 CUDA 版本对得上，这是最常见的卡点。

2
从 LoRA 开始，别全参微调

全参微调显存要求高得多。先用 LoRA 加小学习率跑通，看 loss 曲线降不降，再决定要不要加码。

3
准备数据集用它的格式

先照官方给 alpaca 格式改一份小样本（几百条），跑通了再扩量。数据集格式错是最常见的失败原因。

适合与不适合

不适合的部分比适合更值得看

适合你，如果

  • 第一次做微调，想先看有没有效果
  • 要把自己的领域数据灌进开源模型
  • 快速比较不同数据集和超参的组合

换别的，如果

  • 超大规模分布式训练——换 Axolotl 或自研
  • 需要深度定制训练循环和损失函数
  • 完全不碰命令行，因为它起服务仍要终端
