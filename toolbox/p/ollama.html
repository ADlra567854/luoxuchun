它解决的是哪一步

先把定位说清楚，再决定要不要装
它把「下载模型、起服务、开对话」压成了一条 ollama run。底层是 llama.cpp，默认在 11434 端口开一个 OpenAI 兼容接口，所以你的应用不用改代码就能换成本地模型。真正的价值不是能跑，而是把一个原本要折腾半天的环境问题变成了三分钟的事。

上手三步

按顺序走，卡住基本都在第一步
1
装客户端

Windows 和 macOS 直接下安装包；Linux 用 curl -fsSL https://ollama.com/install.sh | sh。装完 ollama -v 能出版本号就算通。

2
拉一个模型

ollama run qwen3 会自动下载并进入对话。模型越大显存吃得越多，8GB 显卡先从小参数版本试，别一上来点满。

3
接到自己的程序

它已经在 http://localhost:11434/v1 暴露了 OpenAI 兼容端点，base_url 指过去、api_key 随便填一个非空值即可。

适合与不适合

不适合的部分比适合更值得看

适合你，如果

  • 本地试模型、比较不同参数档的实际手感
  • 做原型和 Demo，不想先解决部署问题
  • 单机开发环境，自己一个人用

换别的，如果

  • 5 并发以上的对外服务——吞吐撑不住，换 vLLM
  • 需要张量并行跑超大模型的多卡场景
  • 要做细粒度的批处理调度和显存配额
