它解决的是哪一步

先把定位说清楚，再决定要不要装
PagedAttention 是它提出来的，核心思路是把 KV Cache 像操作系统管内存那样分页，避免显存碎片。结果是同样的卡能扛更多并发。连续批处理、张量并行、OpenAI 兼容服务一个不缺。学习曲线真实存在，但并发一过五，省下来的卡钱就回本了。

上手三步

按顺序走，卡住基本都在第一步
1
备好 CUDA 环境

它和显卡驱动、CUDA 版本绑得很紧。先确认 nvidia-smi 正常，再按官方文档装对应版本，别用系统自带的旧 torch。

2
起服务

pip install vllm 之后 vllm serve <模型路径>。多卡加 --tensor-parallel-size，显存不够先调 --gpu-memory-utilization 到 0.9。

3
压测再上线

用 vllm bench 或自己的压测脚本量并发下的首字延迟和吞吐，这两个数才决定你要几张卡。

适合与不适合

不适合的部分比适合更值得看

适合你，如果

  • 多并发的 API 服务，要把显卡跑满
  • 团队共用一套推理服务，需要稳定的 OpenAI 兼容接口
  • 多卡部署大模型，需要张量并行

换别的，如果

  • 只想本地点开就聊——太重了，用 Ollama
  • 没有 NVIDIA 显卡的机器
  • 只需要跑一两个小模型做实验
