采购前先算这笔账

先分清「训练成本」和「推理成本」。大多数人只关心后者。推理成本 = 单价 × 月 token 量，量小的时候云 API 永远更便宜； 只有当月 token 量稳定超过几亿，自建 GPU 的折旧才开始划算——而且要把运维人力算进去。

免费额度是获客手段，不是长期方案。国内几家（百炼、硅基流动、智谱、混元）的免费额度加起来够个人用很久， 但都有限速与「仅实时推理」之类的约束。做产品时把它当开发期补贴，别写进成本模型。
