21 号毕业设计：DataCleaner 数据清洗工

本项目解决结构化数据清洗流程重复、规则零散、人工操作易漏错的痛点，覆盖缺失值、异常值、重复项三类核心脏数据场景，学完可掌握可复用数据清洗流水线搭建、数据质量规则量化、异常检测算法落地的工程能力。

项目简介

《DataCleaner 数据清洗工》是一款轻量级结构化数据自动清洗工具，面向 CSV/Excel 格式的业务数据集，无需复杂配置即可完成标准化清洗流程，输出可直接用于建模、分析的干净数据集与数据质量报告。工具定位为数据分析、机器学习流程的前置预处理组件，兼容 pandas 生态，可直接嵌入现有数据处理工作流，也支持独立命令行调用，单文件数据集清洗效率较纯人工操作提升 80% 以上，同时内置可追溯的清洗日志，避免数据篡改无据可查的问题。项目默认适配中小规模（100万行以内）的表格数据，支持自定义规则扩展，满足不同业务场景的清洗需求。

功能特性

  • 多格式数据自动加载：支持 CSV、XLSX 格式文件读取，自动识别编码格式（utf-8/gbk/gb2312）、分隔符与表头位置，避免乱码、列错位问题。
  • 缺失值智能处理：自动统计每列缺失率，针对数值列默认采用中位数填充、分类列默认采用众数填充，缺失率超过 60% 的列自动标记并提示删除，支持自定义填充策略。
  • 异常值自动检测修正：基于 3σ 原则、IQR 箱线图法双重检测数值列异常值，支持极值截断、分位数替换两种修正策略，分类列自动识别大小写不一致、前后空格、枚举值越界问题。
  • 重复项精准去重：支持全字段重复、主键列重复两种检测模式，自动保留第一条非重复记录，输出重复项数量与占比统计。
  • 清洗全链路日志追溯：每一步清洗操作均记录操作类型、影响行数、处理规则，最终生成结构化清洗报告（JSON+Markdown 双格式），可回溯每处数据变更。
  • 清洗结果一键导出：支持输出清洗后的 CSV/Excel 文件，同时保留原始数据备份，避免误操作导致源数据丢失。

技术架构

组件技术选型作用
数据IO层pandas、openpyxl、chardet完成多格式文件读取、编码自动识别、结果导出，兼容主流结构化数据格式
核心清洗引擎numpy、scipy.stats实现缺失值统计计算、异常值分布检测、重复项哈希比对的核心逻辑
规则配置层pydantic、PyYAML定义清洗规则参数的数据结构，校验用户自定义配置的合法性，支持YAML格式规则导入
报告生成层jinja2、json基于模板渲染可读的Markdown格式清洗报告，同时输出结构化JSON报告供程序调用
命令行交互层click提供简洁的命令行调用入口，支持参数自定义，降低使用门槛
日志模块logging记录全流程清洗操作日志，支持错误定位与操作追溯

架构说明：整体采用分层解耦设计，数据IO层负责与本地文件交互，将原始数据转换为统一的DataFrame格式传入核心引擎；核心清洗引擎按照「缺失值处理异常值处理重复项处理」的固定流水线执行，每一步执行结果同步写入日志模块；规则配置层为引擎提供可配置的规则参数，无需修改代码即可适配不同场景的清洗阈值；最终处理完成的数据集经IO层导出，同时由报告生成层汇总全流程统计指标输出质量报告，各模块通过标准DataFrame结构交互，可单独替换某层实现（如替换异常值检测算法、新增数据库IO支持）而不影响其他模块逻辑。

核心代码骨架

import pandas as pd
import numpy as np
import logging
from pydantic import BaseModel
from typing import Optional, Literal

# 清洗规则配置模型，校验参数合法性
class CleanConfig(BaseModel):
    missing_threshold: float = 0.6  # 缺失率超过该值则建议删除列
    outlier_method: Literal["iqr", "3sigma"] = "iqr"  # 异常值检测方法
    outlier_strategy: Literal["clip", "quantile"] = "clip"  # 异常值处理策略
    duplicate_subset: Optional[list[str]] = None  # 去重依据列，None则全字段匹配
    save_backup: bool = True  # 是否备份原始数据

class DataCleaner:
    def __init__(self, config: Optional[CleanConfig] = None):
        self.config = config or CleanConfig()
        self.report = {"original_rows": 0, "original_cols": 0, "operations": []}
        logging.basicConfig(level=logging.INFO, format="%(asctime)s - %(levelname)s - %(message)s")
        self.logger = logging.getLogger(__name__)

    def load_data(self, file_path: str) -> pd.DataFrame:
        """数据加载模块：自动识别编码与格式，返回标准DataFrame"""
        # 先通过chardet识别编码，再根据后缀选择pandas对应读取方法
        if file_path.endswith(".csv"):
            with open(file_path, "rb") as f:
                encoding = chardet.detect(f.read(10000))["encoding"]
            df = pd.read_csv(file_path, encoding=encoding)
        elif file_path.endswith(".xlsx"):
            df = pd.read_excel(file_path, engine="openpyxl")
        self.report["original_rows"], self.report["original_cols"] = df.shape
        self.logger.info(f"数据加载完成，共{df.shape[0]}行{df.shape[1]}列")
        return df

    def _handle_missing(self, df: pd.DataFrame) -> pd.DataFrame:
        """缺失值处理子模块：按列类型与缺失率执行对应策略"""
        # 遍历每列计算缺失率，超阈值则记录待删除，否则按类型填充
        for col in df.columns:
            missing_rate = df[col].isna().mean()
            if missing_rate > self.config.missing_threshold:
                df.drop(columns=[col], inplace=True)
                self.report["operations"].append({"type":"drop_col_missing", "col":col, "missing_rate":round(missing_rate,2)})
                continue
            if pd.api.types.is_numeric_dtype(df[col]):
                fill_val = df[col].median()
            else:
                fill_val = df[col].mode()[0] if not df[col].mode().empty else "UNKNOWN"
            df[col].fillna(fill_val, inplace=True)
        return df

    def _handle_outlier(self, df: pd.DataFrame) -> pd.DataFrame:
        """异常值处理子模块：按配置方法检测并修正数值列异常值"""
        numeric_cols = df.select_dtypes(include=np.number).columns
        for col in numeric_cols:
            # 按IQR/3σ计算上下限，执行截断或分位数替换
            if self.config.outlier_method == "iqr":
                q1, q3 = df[col].quantile(0.25), df[col].quantile(0.75)
                iqr = q3 - q1
                lower, upper = q1 - 1.5*iqr, q3 + 1.5*iqr
            else:
                mean, std = df[col].mean(), df[col].std()
                lower, upper = mean - 3*std, mean + 3*std
            outlier_cnt = df[(df[col]<lower)|(df[col]>upper)].shape[0]
            if self.config.outlier_strategy == "clip":
                df[col] = df[col].clip(lower, upper)
            else:
                df.loc[df[col]<lower, col] = lower
                df.loc[df[col]>upper, col] = upper
            self.report["operations"].append({"type":"handle_outlier", "col":col, "outlier_cnt":outlier_cnt})
        return df

    def clean(self, df: pd.DataFrame) -> pd.DataFrame:
        """清洗主流水线：按顺序执行缺失值异常值重复项处理"""
        if self.config.save_backup:
            df.to_csv("backup_original_data.csv", index=False, encoding="utf-8-sig")
        df = self._handle_missing(df)
        df = self._handle_outlier(df)
        # 重复项处理
        before_dup = df.shape[0]
        df.drop_duplicates(subset=self.config.duplicate_subset, inplace=True, keep="first")
        self.report["operations"].append({"type":"drop_duplicates", "removed_cnt":before_dup - df.shape[0]})
        self.report["clean_rows"], self.report["clean_cols"] = df.shape
        self.logger.info("数据清洗完成")
        return df

运行步骤

  1. 准备Python 3.9+环境，创建独立虚拟环境并激活：Windows执行python -m venv venv && venv\Scripts\activate，Mac/Linux执行python3 -m venv venv && source venv/bin/activate。
  2. 安装依赖包：执行pip install pandas==2.1.4 numpy==1.26.3 openpyxl==3.1.2 chardet==5.2.0 pydantic==2.5.3 jinja2==3.1.3 click==8.1.7 pyyaml==6.0.1，固定版本避免兼容性问题。
  3. 将上述核心代码保存为datacleaner.py，同目录下新建cli.py作为命令行入口，基于click实现参数接收（接收输入文件路径、输出路径、配置文件路径三个核心参数）。
  4. （可选）编写自定义清洗规则配置文件config.yaml，可调整缺失率阈值、异常值检测方法、去重主键列等参数，不提供则使用默认配置。
  5. 准备待清洗的测试数据集（可使用kaggle公开的泰坦尼克号数据集titanic.csv作为测试样本），放置在项目同目录下。
  6. 执行清洗命令：python cli.py --input titanic.csv --output cleaned_titanic.csv --config config.yaml，等待执行完成。
  7. 查看输出结果：同目录下会生成清洗后的cleaned_titanic.csv、原始数据备份文件、clean_report.md质量报告，打开报告即可查看各步骤清洗影响的行数与规则明细。

扩展思路

  • 新增高级异常检测能力：引入孤立森林、LOF局部离群因子算法（基于scikit-learn实现），支持高维数据的异常点检测，适配复杂业务数据集的异常识别需求。
