本地部署手册

Ollama、Stable Diffusion等本地AI工具的完整部署指南

白驹 · 全局大脑 · 本地优先
本地AI部署完全指南
01

为什么要本地部署？

隐私安全：数据不出本地，完全私密。
离线可用：无网络也能使用。
零成本：一次部署，永久免费（除电费）。
定制化：可微调、可扩展、完全掌控。

02

Ollama：最简单的方式

安装：curl -fsSL https://ollama.ai/install.sh | sh
运行模型：ollama run qwen2.5:1.5b
常用模型：qwen2.5（中文好）、llama3.1（英文好）、deepseek-r1（推理强）
API调用：默认端口11434，兼容OpenAI格式。

03

LM Studio：图形界面

特点：无需命令行，图形界面操作。
功能：模型下载管理、聊天界面、API服务器、性能监控。
适合：完全不懂命令行的小白用户。
下载：lmstudio.ai

04

Stable Diffusion WebUI

功能：本地AI绘画，文生图、图生图、 inpainting、模型训练。
安装：git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui
要求：NVIDIA显卡（6GB+显存推荐）
模型站：civitai.com、liblib.art

05

ComfyUI：节点式工作流

特点：可视化节点编辑，灵活度高，可复现。
优势：适合复杂工作流，可分享配置。
社区：大量开源工作流可直接使用。
适合：有一定基础的进阶用户。

06

硬件要求参考

最低配置：8GB内存 + 核显 可运行1.5B模型
推荐配置：16GB内存 + RTX 3060 12GB 流畅运行7B模型
高端配置：32GB内存 + RTX 4090 24GB 可运行13B+模型
Mac用户：M1/M2/M3芯片，统一内存架构适合AI推理。

07

常见问题

Q：本地模型效果比云端差？
A：小模型（1.5B-7B）确实不如云端大模型，但隐私和成本优势明显。
Q：需要什么显卡？
A：NVIDIA显卡最佳，AMD次之，Intel核显也能跑小模型。
Q：模型文件多大？
A：1.5B约1GB，7B约4GB，13B约8GB，70B约40GB。

08

推荐学习路径

第一步：安装Ollama，运行qwen2.5:1.5b体验
第二步：尝试不同模型，找到适合自己的
第三步：学习API调用，集成到自己的应用
第四步：尝试Stable Diffusion本地绘画
第五步：探索模型微调（可选进阶）

核心建议：本地部署是AI进阶的必经之路。从Ollama开始，逐步探索，你会发现一个完全不受限的AI世界。
