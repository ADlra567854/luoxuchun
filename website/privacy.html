隐私政策

本政策说明白驹（ccowork）如何处理你的数据。核心原则只有一句话：本地优先，数据归你，透明可审计。

1. 数据归属

你通过白驹工作台生成的对话、图片、视频、代码、笔记等创作内容，默认优先保存在你的本地浏览器或你指定的本地目录。白驹不会无故收集、分析或出售你的创作数据。

2. 我们收集什么

  • 本地状态：主题偏好、最近打开页面、工作台布局等仅保存在浏览器本地存储（localStorage）。
  • 运行日志：站点运行错误日志可能匿名上报，用于稳定性修复，不含个人信息。
  • 第三方 API：当你主动调用 AI 模型生成内容时，请求会发往对应的模型服务商（如豆包方舟、DeepSeek、智谱）。请同时遵守对应服务商的隐私政策。

3. 我们不做什么

不会在未经你授权的情况下读取本地文件系统、不会将你的提示词或生成结果用于模型训练、不会向第三方出售你的数据。

4. 本地部署版本

当你使用白驹本地部署版本或未来自建后端版本时，所有数据、密钥、调用记录均存储在你自己的服务器或设备上，白驹官方无法访问。

5. 变更与联系

本政策可能随产品形态升级而更新。重大变更会在站点公告或更新日志中说明。如有疑问，可通过 GitHub Issues 或首页反馈入口联系我们。
